# 论文创新性对照（sparse_q 分支，2026-10-17）

> 目标：把"我们做了什么、与谁交叠、可辩护的差异点在哪里"写清楚，
> 供 Method/Introduction 直接取用；数据证据指向 `reports/EXPERIMENT_REPORT_zh.md`。

## 1. 候选创新点（按证据强度排序）

### C1（主创新）"候选池结构 > 选择策略"的可复现证据与双路线池
* 说法：在固定真实 FE 预算下，GWO 的收益主要来自**候选池如何构成**
  （α 局部精化 + 仅来自已验证精英的多区域候选），而不是"如何筛选/调度名额"。
* 证据：定向筛选 1.39×、informed-in-strata 1.53×、固定配额偏离
  1.02–1.67×、随机配额 1/7 胜、三种 Q 0.99–1.13×（全部对同池均匀随机）；
  而双路线池 + 均匀随机把 GWO 从 13.59 名提到 5.97 名（17 算法、29 函数、30 种子）。
* 与文献差异：SS-RLPSO/SAQ-CSO 的贡献在"筛掉哪些粒子"；我们证明在 GWO 上
  这类几何筛选会饿死狼自身的移动，收益来自池的构成。（文献报告 §1）

### C2（次创新）细粒度评价密度 K=10 的稳定优势
* 说法：在等 FE 下，把每代真实评价从 50 降到 10（代数 ×10）在两套独立开发
  种子上一致更好（0.970/0.955，均 6/8），正式批早期（FE10/20：0.802/0.777）
  与最终（0.525）均领先标准 GWO；D=100 与 20k 预算下同样领先。
* 与文献差异：旧工程把"最优评价密度"当作 U 形平台（K∈[0.25,0.5]·2N）；
  本工作在**不同池结构**下把最优点推到更细端（K=10≈0.1·2N），并且给出了
  与池比例、筛选规则的交互证据。

### C3（诚实负结果，作为贡献的一部分）轻量 Q 调度不优于最优固定配额
* 三种 Q 变体（零初值/调参/先验初值）对最优固定 0.99/1.02/1.13，仅胜随机
  配额（0.75–0.87）；先验初值退化为 93% 单动作。对 QLFDGWO（2026）、
  Drones（2025）的 Q-GWO 线索，本结果说明：在这些任务上"学习调度"的增益
  被"选对一个常数"覆盖，论文不得声称 RL 独立有效。

### C4（工程）验证锚 + 原子提交的稀疏接口
* 未评价候选永不进入任何排序/领导/档案；全部真实 FE 由独立探针计费；
  抽样逐位复现 ≤3.2e-15；4 worker 全批次 0 失败。作为可复现性卖点。

## 2. 与近年文献的逐条对照（重叠度/差异点）

| 文献 | 重叠 | 我们的差异 |
|---|---|---|
| QLFDGWO（Biomimetics 2026） | Q-learning + GWO | 它用 Q 引导加权适应度-距离（UAV）；我们给 Q 分配"昂贵真实评价名额"并**证明其无独立收益** |
| Adaptive Q-Learning GWO（Drones 2025） | Q + GWO | 同上；我们是等 FE 的 CEC2017 基准与完整消融 |
| SS-RLPSO（导师） | 空间筛选 + Q 调度 | 我们改"候选池构成"而非筛除粒子；且 Q 无收益 |
| SAQ-CSO（9.29 线） | 稀疏评价 + 几何筛选 + Q 配额 | 同上；我们在 GWO 上给出"几何筛选有害"的对照 |
| I-GWO（ESWA 2021） | 强 GWO 基线 | 我们不复用 DLH；对拍为统计平手偏优（正式批 +12/−6；D=100 +5/−1） |
| DLMDGWO / SGWO / RL-LGWO / DMSGWO | 多种群/重尾/RL 领导 | 我们不变搜索方程、不加重尾；只改评价接口 |
| Surrogate-assisted GWO（2020） | 昂贵优化 + GWO | 我们无代理模型，纯稀疏真实评价 |

## 3. 可写/不可写清单

可写：双路线稀疏框架；"池结构>选择策略"的证据；K=10 的细粒度优势；
Q 无收益的负结果；与 I-GWO/SAQ-CSO 的统计平手；D100/20k 的一致性。
不可写：首次 Q-GWO/稀疏评价；"超越所有基线"；把 Q 写成有效组件；
把 D=100 的 12 函数子集结果说成全 29 函数。
