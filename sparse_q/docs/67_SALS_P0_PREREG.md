# 67. SALS P0 被动审计预注册

日期：2026-10-22
状态：运行前冻结。

## 0. 机制与主问题

SALS（post-selection stratified coefficient sampling）：每代 M=100 个候选只有 K=10 个获得真实评价（其中 G1 约 n≈5 个）。
既然**随机筛选不依赖候选位置**，那么在**筛选之后**、只对真正被评价的 G1 候选重新抽取
`(A1,C1,A2,C2,A3,C3)` 系数（6D 维），并让这些样本在每一维上分层（Latin-hypercube）——
是否能比"同样时机但 IID 重抽"产生更有效的搜索结果？

- B 臂（对照）：筛选后用 **IID** 重抽系数；
- C 臂（SALS）：筛选后用 **LHS 分层**重抽系数（每一维 n 个样本落在 n 个不同层，逐维独立随机置换）；
- 两臂都保留 STEER 规则（同样的触发概率与随机方向，从同一独立流抽取），因此两臂**唯一差别**是 IID vs 分层 ✓。

## 1. 审计设计（P0，影子模式）

- CEC2017，D=50，100,000 真实 FE；STEER 开启；G1、E、筛选、接受、FE 全部冻结；
- 8 个函数：F1、F3、F4、F7、F10、F13、F20、F30；
- 新种子：**3434–3438**（运行前扫描确认未使用）；
- 1 个审计臂 × 8 函数 × 5 种子 = **40 次运行**；
- `salsMode='audit'`：同时计算 B、C 两个反事实重抽并记录几何量，但候选仍用冻结版本 →
  轨迹必须与 `SGWO_STEER3` 逐位一致（合约测试）。

## 2. 记录指标（每代聚合）

| 指标 | 定义 |
|---|---|
| `SalsNMean` | 每代被评价 G1 候选数均值（预期 ≈5） |
| `SalsStratFrac` | LHS 构造中"该维 n 个样本落在 n 个不同层"的比例（构造正确性，应 =1） |
| `SalsDispBMean` / `SalsDispCMean` | 被评价 G1 候选位置的平均最近邻距离 / 跨度（B / C） |
| `SalsShiftBMean` / `SalsShiftCMean` | 重抽后位置相对原候选位置的位移 / 跨度（B / C） |

## 3. P0 通过条件（预注册，必须全部满足）

1. **分层被正确实现**：所有 40 次运行 `SalsStratFrac = 1.0`；
2. **分层确实传播到位置**（文本要求 ②）：≥6/8 个函数，`SalsDispCMean / SalsDispBMean` 中位数 ≥ 1.01
   （分层使被评价候选的位置离散度至少提高 1%）；
3. **重抽确有实质作用**：≥6/8 个函数，`SalsShiftBMean` 与 `SalsShiftCMean` 中位数均 ≥ 0.01 跨度；
4. **完整性**：`audit` 与 `SGWO_STEER3` 逐位一致（合约测试）。

## 4. 判定与停止规则

- 全部通过 → `PROMOTE_SALS_TO_P1`：三臂（A 冻结 / B post-selection IID / C post-selection LHS）
  15 函数 × 10 新种子；**主假设是 C/B**（不是 C/A）；
- 第 2 条不通过（分层无法转化为位置离散度）→ 停止 SALS，不扫描层数、系数类型或分层概率；
- 第 1/3 条不通过 → 先修实现（构造或重抽语义），不进入性能实验。
