# 60. STEER 确认级复评预注册（当前 G1+E 框架，逐位一致的逐狼实现）

日期：2026-10-22
状态：运行前冻结。种子 3071–3100（新臂从未在该种子块上运行）。

## 0. 为什么直接做确认级

1. **dev 批次（`58_STEER_DEV_PREREG.md`，600 次）判定 INCONCLUSIVE_VECTORISATION**：
   向量化对照臂 V 相对逐狼冻结臂 A 的中位比 1.026、3 个函数 >1.20 → 实现差异不可忽略，该批不能用来说明机制；
2. 该批仍给出方向性信息：随机方向扰动 B/A 中位 0.951（9/15 胜），而成功方向 C/B=1.023（方向信息再次无贡献）；
3. 仓库历史在 **V1 配置**上已有 29 函数 × 10 种子的正面证据（`docs/12_SDIR_AUDIT.md`）：
   V2-G1 vs V1 中位 0.967（25-4 胜，p=1.9e-05）、V2-Random vs V1 中位 0.938（17-12 胜，p=1.1e-03），
   但方向归因失败（G1 vs Random 0.988，CI 含 0）且运行时间 +17%–25%；
4. 本次用**与 `SGWO_ABLATION` 逐位一致的逐狼实现**（合约测试 `test_steer_contract` 断言 bitwise 相同），
   在当前 (G1+E, G2 off) 构型上做确认级复评。

## 1. 设计

- CEC2017，D=50，29 函数（F1、F3–F30），100,000 真实 FE；种子 **3071–3100**（30 个）；
- 臂：

| 臂 | 设置 | 来源 |
|---|---|---|
| A2 | 冻结 G1+E | **复用** `ablcore_20261017_062209`（已通过 reuse 测试） |
| A0 | 无 E 冻结 | **复用** 同批次 |
| B | `perwolf` + 随机方向扰动（succSteer=0.5, λ=0.5, sdirSource='random'） | 新跑 870 |
| C | `perwolf` + 成功方向扰动（sdirSource='g1'） | 新跑 870 |
| D | 随机方向扰动 + E 关 | 新跑 870 |

## 2. 预注册门槛

**主门槛（性能）**：B 或 C 同时满足

- 相对 A2 的逐函数中位误差比 ≤0.98；
- ≥18/29 个函数获胜；
- 没有函数的中位误差比 >1.20；

**报告项（不作门槛）**：

- 运行时间比（该机制固有 +per-wolf 向量运算开销；历史测量 1.17–1.25×）；
- 方向归因 C 对 B；
- E 关臂 D 对 A0（正交性）；
- 早期 FE 检查点 10/20/50/80/100% 的轨迹（历史证据显示增益主要出现在 100% 预算处，需要在本框架复核）；
- 逐函数配对 Wilcoxon + Holm。

## 3. 判定

- 主门槛通过（B 或 C）→ `PROMOTE_STEER`：作为与 E 正交的第二机制（"等步长方向扰动"），
  并在论文中如实报告方向归因结论（随机方向与成功方向无差异 → 不能声称"方向记忆"）；
- 不通过 → 停止 STEER 与全部方向/扰动类机制，第二机制回到已确认非劣的 TSD-base 或单机制叙事。
