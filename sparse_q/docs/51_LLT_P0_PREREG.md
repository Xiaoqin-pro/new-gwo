# 51. LLT-P0 被动审计预注册：局部领导拓扑

日期：2026-10-22
状态：被动审计（P0），运行前冻结。

## 0. 机制（LLT, Local Leader Topology）

在冻结 G1+E 框架上，只改变 G1 候选使用的**领导集合来源**：

- 现在：全部 50 只狼使用同一组全局领导 {alpha, beta, delta}；
- LLT：第 i 只狼使用**固定环形窗口** `W_i = {i-3, ..., i+3} (mod 50)` 内
  **真实评价适应度最好的 3 只狼**作为它自己的 (alpha_i, beta_i, delta_i)；
- 领导聚合公式、A/C 随机数结构、逐维更新式、候选数量、筛选、E、档案、接受规则、
  真实 FE 计费**全部不变**；
- 匹配对照 `ringrand`：同一环形窗口，但 3 个领导在该窗口内**随机**抽取
  （按适应度排序后代入同样的位置），随机数消耗与 `ring` 完全一致。

机制动机（借鉴老师 RL_GNN_PSO 的 GNN 拓扑思想，取最简形式）：

- 稀疏评价下每代只评价 K=10/100 个候选，领导更新相对缓慢；
- 全局领导使 50 个 G1 候选向同一组点坍缩，评价预算可能被近邻重复候选占用；
- 固定环形拓扑让每只狼锚定自己邻域内的已验证优秀个体，形成多个并行子群，
  从而在不增加任何真实评价、也不改动 E 的前提下提高池内覆盖。

参数在预注册中固定，不扫描：窗口 `lltWindow=7`，领导数 `lltLeaders=3`。

## 1. 审计实现（被动，行为不变）

`SGWO_LLT.m` 的 `lltMode='audit'`：所有候选仍按冻结规则生成，
只额外记录以下量（使用与真实候选生成**完全相同的 A/C 随机系数**做反事实）：

| 指标 | 定义 |
|---|---|
| `LltLocalNeGlobalRate` | 窗口内最优狼不是全局 alpha 的狼比例（拓扑是否真的与全局不同） |
| `LltDispMedian` | 反事实局部领导聚合位置与冻结全局位置之差的范数 / 跨度，代中位数 |
| `LltDupSelectedRate` | 每代被选中的 K 个候选中，与其同代另一个被选中候选距离 <2% 跨度的比例 |
| `LltG1NNMedian` | G1 池内随机 10 个子样本到最近同池候选的距离中位数 / 跨度 |
| `LltPhaseDisp` | 上述位移在早期(≤25%)/中期(25-60%)/后期(>60%)的均值 |

审计模式必须与冻结 G1+E 的 Trace / Best / FE 逐位一致（合约测试 `test_llt_audit_contract`）。

## 3. 通过条件（预注册）

同时满足：

1. ≥6/8 个函数：`LltLocalNeGlobalRate` 中位数 ≥ 0.50（局部拓扑确实不同于全局）；
2. ≥6/8 个函数：`LltDispMedian` 中位数 > 0.01（反事实候选变化具有实际幅度）；
3. ≥6/8 个函数：`LltDupSelectedRate` 中位数 ≥ 0.10（存在被评价冗余前提）；
4. 审计逐位一致（合约测试通过）。

未通过 → 停止 LLT，不进入主动实验，不扫描窗口大小或领导数量。
