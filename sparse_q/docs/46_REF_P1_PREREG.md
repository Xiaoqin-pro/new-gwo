# 46. REF P1 预注册：多样性填充槽位

## 0. 机制定位

NEL 预实验显示，替换 12 个冗余 GWO 填充槽位可能有性能信号，但邻域维度学习本身没有优于随机榜样对照，且实现过慢。因此只保留更小、更快的候选源机制 REF：

- G2 关闭后，12 个槽位不再由标准 GWO 候选填补；
- REF 候选 = 随机选择一个当前狼的位置 + 使用当前成功尺度 `sigB` 的均匀扰动；
- 只替换候选源，不改变 G1、E、M=100、K=10、真实 FE、筛选或档案规则。

REF 使用独立随机流，不读取档案信息，因此与 E 的多区域空间记忆正交。

## 1. 对照

| 臂 | 12 个填充槽位 | 用途 |
|---|---|---|
| A | 标准 GWO 填充 | 冻结基准 |
| B | REF 随机狼 + 成功尺度扰动 | 检验局部多样性填充 |
| C | 均匀随机移民 | 检验收益是否只是任意多样性 |

## 2. 实验协议

- CEC2017，D=50；
- 15 个函数：F1、F3、F4、F7、F10、F11、F13、F14、F16、F18、F20、F22、F24、F26、F30；
- 种子：3306–3315（运行前扫描历史 CSV 确认未使用）；
- 真实 FE：100,000；
- 3 臂 × 15 函数 × 10 种子 = 450 次运行。

## 3. 晋级门槛

### H1：REF 相对标准填充有净收益

- B/A 中位误差比 ≤0.98；
- 至少 11/15 个函数获胜；
- 没有函数中位误差比 >1.20；
- 运行时间比 B/A ≤1.15。

### H2：REF 优于均匀随机移民

- B/C 中位误差比 ≤0.98；
- 至少 11/15 个函数获胜；
- 没有函数中位误差比 >1.20。

如果 H1 通过但 H2 不通过，只能声称“替换填充槽位有效”，不能声称局部种群信息是关键。若 H1 不通过，停止 REF，不扫描扰动尺度或填充方式。
