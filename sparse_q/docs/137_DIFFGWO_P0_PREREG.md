# Diff-GWO P0 预注册（2026-10-24）

## 机制

在冻结的 GWO `G1+E+STEER` 框架内，把 G1 更新方程从纯 α/β/δ 领导聚合替换为带已验证档案的差分算子：

```
xg_i = X_i + F·(α − X_i) + F·(X_r1 − X_pool_r2),   F = 0.5
```

其中 `X_i` 是当前狼，`α` 是全局最优，`X_r1` 从狼群抽取，`X_pool_r2` 从「狼群 ∪ 已验证档案」抽取。E、STEER、K=10、M=100、Screening 和真实 FE 计费全部不变；只改 G1 候选如何生成。它保持 GWO 的领导结构（α 仍是收敛锚）并复用已验证档案的差分方向，属于框架内算子改进。

前置证据（20k FE dev，独立种子块）：

| 批次 | DiffAll/Standard |
|---|---|
| diffhybrid20（4212–4213） | 0.7446，5/8 |
| rankdiff20（4214–4215） | 0.8804，5/8 |
| opq20（4218–4219） | 0.8745，4/8 |
| opq2（4220–4221） | 0.8959，5/8 |

4 个独立块一致改善、0–2 个尾部。但 **没有任何一臂直接检验：(a) 已验证档案的差分方向是否有用；(b) 方向本身是否好于同幅度随机探索**。本 P0 补上这两个归因对照。

## P0 协议

- CEC2017，D=50，N=50，K=10，M=100，100k 真实 FE。
- 8 函数：F1/F4/F7/F10/F13/F20/F24/F30。
- 5 个全新种子：4281–4285。
- 4 个 worker，5 臂 × 8 × 5 = 200 次运行。
- 臂：
  - A-Standard：冻结 G1+E+STEER，opFixed=1。
  - B-DiffAll：全部 G1 用差分算子，r2 来自狼群∪档案。
  - C-DiffNoArc：同 B，r2 只来自狼群（去掉已验证档案）。
  - D-DiffShuffle：同 B，差分向量 `X_r1−X_pool_r2` 坐标随机置换。
  - E-DiffRandom：同 B，r1/r2 替换为两个均匀随机点（幅度等价探索对照）。

## 固定门槛（用户放宽口径：允许少数函数恶化，要求大多数向好）

1. `B/A` 中位误差比 ≤ 0.95，至少 6/8 函数胜出，>1.20 不超过 2。
2. `B/C` 中位 ≤ 0.98，至少 5/8 胜出（已验证档案差分是正贡献）。
3. `B/D` 中位 ≤ 0.98，至少 5/8 胜出（差分方向信息有效，而非只靠幅度）。
4. `B/E` 中位 ≤ 0.98，至少 5/8 胜出（不是等价的随机探索）。
5. 运行时间 `B/A` ≤ 1.30。

通过 → 15 函数 × 10 种子 P1（继续复用现役种子块）；不通过 → 记录 STOP，不进入 P1，DiffAll 不作为独立贡献。

## 归因

A↔B：差分算子整体；B↔C：已验证档案在差分中的贡献；B↔D：方向对齐的信息量；B↔E：与同幅度随机探索的区分。
