# 90. DSEP（自适应分离尺）确认级预注册

日期：2026-10-23　状态：**确认完成；按门槛 STOP（强 near-miss）**

## 1. 前提（现有数据，零成本）

`diag_p0_20261023_021212`（40 次被动审计，逐位一致）记录的**新中心出生**按 FE 十分位：
443.8 → 61.9 → 47.1 → 37.4 → 27.8 → 19.4 → 18.1 → 10.8 → 3.0 → **0.8**（每 run 平均 670 次出生）。
前 30% FE 占 **82.5%** 的出生，最后 30% 只占 **2.2%**；F1/F4 在最后三个十分位出生数为 **0**。
即：固定盒对角线的 2% 分离阈值在种群收缩后成为不可逾越的门槛，E 在后期无法诞生新的区域中心。

## 2. 机制（论文口径：我们提出……）

**DSEP（Adaptive Separation Reference）**：把档案中心分离判据的**尺子**从固定盒对角线改为种群尺度，阈值 `dSepFrac=2%` 不变：
`spanRef = min(||ub−lb||, 2·RMS_radius(Xv))`（每代更新一次）。这样种群收缩时，新中心仍可在"当前搜索尺度"下诞生。

匹配对照：`half` 臂用**常数** `0.5·||ub−lb||`（≈ 种群初期尺度），用来把"更小的门槛"与"自适应"分开。

`dSepRef='box'` 与冻结实现**逐位一致**（`tests/test_dsep_contract.m` 已断言）。

## 3. 确认级设计（复用冻结臂）

| 臂 | dSepRef | 说明 |
|---|---|---|
| A（复用） | `box` | `steer_robust` 的 `A-Final-SteerOn`，seeds 3459–3488（逐位等价） |
| B | `pop` | 自适应（主假设臂） |
| C | `half` | 常数 0.5 span（对照） |

29 函数 × 30 种子 × 2 新臂 = **1740 次运行**（≈65–70 分钟）。

## 4. 门槛（运行前固定）

- **主假设 B/A**：中位 ≤0.98、≥18/29 胜、无 >1.20、时间 ≤1.15；
- **归因 B/C**：中位 ≤0.98 且 ≥18/29 胜（否则收益只能归因于"门槛变小"，不能归因于自适应）；
- 报告 C/A；过程指标：新中心出生数、平均/末期分离尺。

判定：B/A 且 B/C 通过 → `PROMOTE_DSEP`；仅 B/A → `DSEP_UNATTRIBUTED`；否则 `STOP_DSEP_CONFIRM`（不再扫描 dSepFrac、pop 尺度定义或 k）。
