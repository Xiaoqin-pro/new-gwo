# 113. Dual-Core Portfolio P0/P1 预注册

日期：2026-10-23　状态：**P0 失败，停止**

## 机制

并行维护两个独立强核：

- **CMA-ES 核**：全协方差、旋转/病态搜索；
- **L-SHADE 核**：差分变异、pbest、外部 archive，适合多模态/复合函数；
- 两核共享同一初始化池，但**不互相重置种群、协方差、F/CR 或 archive**；
- 50% 真实 FE 给 CMA，50% 给 LSHADE；最终只共享两者已验证的最优解；
- 总真实 FE 严格等于 100k，初始池评价分别计入各自预算。

该机制的关键不是“换阶段”，而是避免把一方的搜索状态强行塞给另一方；两个核保持独立轨迹，仅通过最终 best 组合。
