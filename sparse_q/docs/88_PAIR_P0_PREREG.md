# 88. PAIR（质量感知精英配对）P0-Value 预注册

日期：2026-10-23　状态：**运行前冻结**

## 1. 机制（论文口径：我们提出……）

两中心插值路线是 E 中生产力最高的子路（诊断 GB 率 0.301% vs 单中心壳 0.003%），
但冻结实现用两次 `randi` **均匀随机**配对中心——档案里最差的中心也会被选中，配对与中心质量完全无关。
**PAIR（Quality-Aware Elite Pairing）**：在名额、插值几何、档案规则、筛选与 FE 全部不变的前提下，
把配对限制在已验证质量较高的中心之间：从**前 3 名**中心随机取 $c_1$，从**前 6 名**中取离 $c_1$ 最远者作 $c_2$
（"优质区域桥接"）。匹配对照 `shuffled` 把中心适应度随机打乱后套用同一规则（保形不保质，随机数消耗完全相同）。

## 2. P0-Value（被动审计，8 函数 × 5 新种子 3574 之前不可用 → 3584 之前的块已用，改用 3614–3618 × 100k FE = 40 次）

`pairMode='audit'`：冻结行为逐位不变（合约测试已断言），只记录被评价的插值候选按
**较优中心的质量排名档**（1 = 最优）：bin1 = rank≤3，bin2 = 4–6，bin3 = >6；
每档记录：评价数、全局最优改进数、档案接纳数（并给出 GB 率与接纳率）。

## 3. 门槛（运行前固定）

对每个函数计算 `GB率(bin1)/GB率(bin3)`（bin3 率用 +0.5 平滑避免除零）与 `接纳率(bin1)/接纳率(bin3)`；
**≥6/8 个函数**满足"bin1 的 GB 事件数 ≥10 **且** 两个比率至少一个 ≥1.5" → 前提成立（质量分层可预测价值）。

通过 → 直接进入确认级（**复用** seeds 3459–3488 的冻结臂；只跑 `quality` 与 `shuffled` 两臂 = 1740 次 ≈50 分钟）；
不通过 → `STOP_PAIR_P0`，不再扫描 top-k 的 k、配对距离准则或插值权重。
