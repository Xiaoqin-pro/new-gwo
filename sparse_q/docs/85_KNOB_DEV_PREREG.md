# 85. KNOB dev 预注册（填充路线扰动 × 评价排序；复用冻结臂）

日期：2026-10-23　状态：**运行前冻结**

## 1. 两个轻量设计项（论文口径：我们提出……）

**(1) 填充路线的等步长扰动（filler-STEER）**：STEER（已确认的等步长随机方向延伸）目前只作用于 G1 路线；
本项把同一算子扩展到**填充路线**（`src==4`，每代 12 个候选，此前从未扰动），
使三条候选流（G1 / E / 填充）使用一致的探索算子。零额外 FE、独立随机流、其余全冻结。

**(2) 价值优先的评价排序（value-first evaluation ordering）**：稀疏评价下 K=10 个名额是**竞争性**的
（档案准入与种群替换都是排他、先到先得）；冻结实现的评价顺序按池索引 = "G1 → 填充 → E"，
即 G1 优先。本项改为**外部候选优先**（E + 填充先评），让已验证区域的信息先占名额。
反向对照天然存在：**冻结臂本身就是 G1 优先**（合约测试已断言 `g1first` 与冻结逐位一致）。

`fillerSteer=0, evalOrder='index'` 与 `SGWO_STEER3` **逐位一致**（`tests/test_knob_contract.m` 已断言）。
