# 61. STJ 确认级预注册：停滞触发的方向抖动（在已确认 STEER 之上）

日期：2026-10-22
状态：运行前冻结。种子 3071–3100（STJ 臂在这些种子上从未运行；A2/B 基线复用）。

## 0. 机制

**STJ（Stagnation-Triggered Jitter）**：与已确认的 STEER 完全相同的算子（以概率 0.5 沿单位随机方向延长
`λ·||xg−x_i||`，λ=0.5），唯一区别是**门控**：

- 当 `FE − FE_lastGB ≥ τ = max(500, 0.02·B) = 2000` 时：按原概率施加扰动；
- 否则：**完全冻结行为**（该代不抽触发随机数、不扰动）；
- 一旦真实评价产生新的全局最优，停滞计数清零、门控自动关闭。

不新增真实 FE、不改候选池/筛选/档案/领导、不新增参数（复用仓库既有停滞阈值与 STEER 的 λ、p）。

## 1. P0 前提（用现有数据完成，无需新跑）

### 1.1 门控覆盖率（450 次冻结 G1+E 轨迹，3 个独立批次）

| 指标 | 中位数 | p10–p90 |
|---|---:|---|
| 全程门控开启比例 | **16.4%** | 4.7%–24.8% |
| 后半程开启比例 | **22.6%** | 6.5%–58.1% |

分函数 4.6%–23.4%；**<5% 的仅 1/15，>95% 的 0/15** → 不退化为"冻结"或"始终 STEER"（对照 WLR：0.68% → 干净停止）。

### 1.2 收益是否集中在停滞窗口（9 组配对轨迹：F1/F13/F30 × 3071–3073）

以冻结臂的停滞窗口为区间，比较两臂的 log10 改善量：

| 臂 | 窗口内 Δgain（中位） | 窗口外 Δgain（中位） | 窗口内胜出 |
|---|---:|---:|---:|
| B 随机方向 STEER | **+0.343** | **−0.204** | **18/18** |
| C 成功方向 STEER | +0.427 | −0.434 | 18/18 |

窗口内冻结臂改善恒为 0（定义使然），而扰动臂仍有 0.34–0.43 decades 改善 → **STEER 的收益全部落在停滞窗口内**，
这正是 STJ 的假设。

### 1.3 实现一致性（合约测试，`test_steer_contract`）

- `stj` 且 τ=0 → 与始终启用 STEER（`perwolf`）**逐位一致**；
- `stj` 且 τ=∞ → 与冻结 `SGWO_ABLATION` **逐位一致**；
- 真实 τ=2000 时：FE 精确、门控确实开启并施加扰动（20k 冒烟中门控 529/1995 代，扰动 26,490 次），
  且搜索轨迹与冻结不同。

## 2. 确认设计

- CEC2017，D=50，29 函数（F1、F3–F30），100,000 真实 FE，种子 **3071–3100**（30 个）；
- 臂：

| 臂 | 设置 | 来源 |
|---|---|---|
| A2 | 冻结 G1+E | **复用** `ablcore_20261017_062209`（已逐位验证） |
| B | 始终启用 STEER（随机方向，p=0.5，λ=0.5） | **复用** `steer_confirm2_20261022_063141` 的 `B-Steer-Rand` |
| C | STJ（同一算子 + 停滞门控） | **新跑 870 条**（本批次唯一新臂） |

## 3. 预注册门槛

- **H1（相对冻结基线）**：C/A2 中位误差比 ≤0.98；≥18/29 个函数获胜；无函数 >1.20；运行时间比 ≤1.10；
- **H2（不劣于始终启用 STEER）**：C/B 中位误差比 ≤1.00，且配对 log 比的 bootstrap 95% CI 上界 ≤1.05；
- **报告项**：C/B 检查点轨迹（10/20/50/80/100%）、STJ 门控开启率与扰动次数、
  逐函数配对 Wilcoxon + Holm、函数族分解、以及与 9 单元冻结参考的终局轨迹。

## 4. 判定

- H1 与 H2 同时通过 → `PROMOTE_STJ`：论文第二机制改用 **STJ**（更省、故事更强："只在停滞时扰动"）；
- H1 通过但 H2 不通过（比 STEER 差 >5%）→ 保留 **STEER** 作为机制，STJ 仅作效率变体记录；
- H1 不通过 → 保留 STEER；**不再扫描停滞阈值 τ、λ 或 p**，逃逸/触发类方向整体停止。
