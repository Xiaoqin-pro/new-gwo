# 14 — 基线复现审计（RL-LGWO / DMSGWO，2026-10-17）

范围：对两份近期 GWO 基线的 MATLAB 实现做复现忠实度审计并修正。**不修改 VAST-GWO(V1)/SGWO 与既有正式结果。**

## 0. 结论（先行）

* **RL-LGWO**：原单版移植确有超出“缓存+计费”的语义改变。现改为**双模式**实现：
  `author`＝逐字忠实作者开源代码（含其已知缺陷，敏感性对照）；
  `paper`＝按论文方法描述修正。**主表预注册采用 `paper` 版**（先于结果决定，不按 CEC 结果挑选）。
* **DMSGWO**：官方源码开发组循环为空（`%%` 占位）。按论文 Eq.(8)(12)(13)(14) 重建，
  标注 **paper-based reconstruction**；骨架（轮首重评/领导更新、探索组 Eq.(10)(11)、动态分组）与官方源码一致。
* 两者共同适配（仅计费/调度，逐条列出）已写入代码头注释与本文件；单元/烟测通过。

## 4. 共同适配（两实现）

1. 评价缓存（去重位置）；2. 调度变量 `fe/budget`；3. 初始种群由实验框架给定（同初始池）；
4. 真实 FE 精确计费（EvalProbe 探针断言 FE==budget）；5. 边界 clamp 与源码一致。

  RLGWO author≠paper（轨迹不同，符合预期）。

  已复用算法（前五个）直接使用 seeds 3001:3030 的既有审计结果；新臂批次 `final7_*`。
