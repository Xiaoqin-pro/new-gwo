## 3. 预注册选择规则（禁止事后更改）

对每个臂 a，计算逐函数 `r_a(F) = median_seed(err_a / err_E38)`：

1. `wins(a) = #{F: r_a(F) < 1}`；
2. 选出候选臂 nE*：在所有 `wins(a) ≥ 9/15` 且 `max_F r_a(F) ≤ 1.20` 的臂中，取 `median_F r_a(F)` 最小者；
3. 若不存在满足条件的臂 → 结论为"**dev 上 38 不可改进**"，不进入确认阶段（这也是一条有效结论，用于冻结 38/12）；
4. 同时记录曲线形状与 20% FE 检查点，用于论文中的敏感性图。
