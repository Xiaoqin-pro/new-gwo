# 75. MSE 确认级测试（阶段 3，最终判定）

日期：2026-10-22/23　状态：**运行前冻结**

## 1. 为什么会有阶段 3（必须如实记录）

- `docs/73` 的 P1（15 函数 × 10 种子 3494–3503）按字面门槛判 `STOP_MSE_P1`：
  B/A 中位比 0.9628、**9/15 胜**、**1 个 >1.20（F13 1.221）**；B/C 0.9865、9/15、2 个 >1.20。
- 但同一份材料里有一个**先于本实验存在**的标尺校准事实（§三十二已记录）：
  用**已确认有效**的 STEER 在**完全相同**的 dev 标尺上测量，得到
  **0.9711、9/15 胜、1 个 >1.20（F24 1.247）** —— 即"真机制"也会被这条 dev 门槛否掉；
  把种子扩到 30 个后同一比较为 0.9440、10/15 胜、0 灾难。
- 因此 dev 门槛（≥11/15 胜且 0 灾难）对 ~3.5% 量级的效应**没有分辨力**（假阴性约 2/3）。
  dev 判定既不能证伪 MSE，也不能证实它。

**结论**：唯一有信息量的检验是确认级（29 函数 × 30 种子、配对、严格门槛）。

## 2. 设计（阶段 3a：主假设）

| 臂 | 来源 | 配置 |
|---|---|---|
| A（冻结终版） | **复用** `steer_robust_20261022_213856` 的 `A-Final-SteerOn`（29 × 30，seeds 3459–3488） | G1+E+STEER（与 `SGWO_MSE` 的 `mseMode='none'` 逐位等价，合约测试已断言） |
| B（MSE） | 本批新跑 | 同配置 + `mseMode='mix'`（单中心壳尺度 {0.5,1,2}σ，概率 {1/3,1/2,1/6}，均值保持） |

协议：CEC2017 D=50、100k 真实 FE、29 函数 [1 3:30]、**同种子 3459–3488**（配对复用冻结臂）、
B 臂 29 × 30 = **870 次运行**。

## 3. 门槛（运行前固定；这是最终判定）

- B/A 函数级中位误差比 ≤ **0.98**；
- **≥18/29** 个函数获胜；
- **无函数 >1.20**；
- 运行时间比 ≤1.15。

**通过 → `PROMOTE_MSE_CONFIRMED`**（MSE 成为第三个机制；随后可做阶段 3b 的归因臂 C）。
**不通过 → `STOP_MSE_CONFIRMED`**：MSE 永久停止，不再有阶段 4、不再改尺度集合/比例/对照常数。

## 4. 阶段 3b（仅在 3a 通过后，另行启动，本条亦预先写定）

C（匹配 RMS 单尺度对照，常数乘子 sqrt(1.25)）在同种子 3459–3488 上跑 870 次：
- 若 B/C 中位 ≤0.98 且 ≥18/29 胜 → 归因成立（多尺度形状而非幅度）；
- 否则只声称"均值保持的离散度放大型 E 壳采样有效"，不得声称"多尺度形状"是关键。
