# 77. Identity-Credit P0 被动审计预注册（当前冻结终版实现）

日期：2026-10-23　状态：**运行前冻结**

## 1. 背景

ENAC 分支（30k FE、旧实现）被动审计发现档案中心信用存在两类缺陷：
**(a) 路由错配**——候选记录的是档案数组下标，评价时该槽位可能已被刷新/替换（wrong update 2.30%、stale 3.23%）；
**(b) 近距离刷新泄漏**——单中心刷新不重置该槽位信用，新点继承旧信用（事件率 83.8%、泄漏信用/总增量 295%）。
ENAC 的 P1 判定为 `IDENTITY_EFFECT_ONLY`：有效成分是身份修正（Identity-Credit 相对 V1 0.96126、6/8 胜、无灾难）。

本线的任务是把这个修正**移植到当前冻结终版（G1+E+STEER，100k FE）**并重新验证其前提与收益。
实现：`src/SGWO_IDC.m`（两开关：`idcStableID` 路由修复、`idcResetOnRefresh` 泄漏修复；ID 记账在所有模式下维护），
合约测试 `tests/test_idc_contract.m`：(0,0) 与 `SGWO_STEER3` **逐位一致**。

## 2. P0 设计（8 函数 × 5 新种子 3549–3553 × 100k FE，4 臂 = 160 次）

| 臂 | idcStableID | idcResetOnRefresh | 用途 |
|---|---:|---:|---|
| A 审计 | 0 | 0 | 被动测缺陷率（行为与冻结终版逐位一致） |
| B 完整 IDC | 1 | 1 | 触发/过程指标 |
| C 仅路由 | 1 | 0 | 触发/过程指标 |
| D 仅重置 | 0 | 1 | 触发/过程指标 |

函数集：[1 3 4 7 10 13 20 30]（仓库标准 audit 集）。

## 3. 门槛（运行前固定）

缺陷 material 条件（审计臂，跨种子中位）：

1. 路由错配率 ≥ **1%**；
2. 失效反馈率（记录 ID 已不存在）≥ **1%**；
3. 刷新泄漏事件率 ≥ **5%**；
4. 泄漏信用 / 总信用增量 ≥ **5%**。

触发（actuation）条件：

5. 臂 B、C 与审计臂的 BestCost **不一致的单元比例 ≥ 50%**（说明路由修复真的改变搜索）；
6. 臂 D 与审计臂不一致的单元比例 ≥ **10%**（泄漏修复在 100k FE 下确实会触发）。

四条缺陷全 material 且三条触发条件满足 → `PROMOTE_IDC_TO_P1`；否则停止该线（不扫描权重形式、不加入曝光归一化）。
