## 2. 预注册选择规则（不得事后修改）

对每个臂 a，计算逐函数 `r_a(F) = median_seed(err_a / err_E38)`：

1. 候选臂需满足 `wins(a) ≥ 9/15` 且 `max_F r_a(F) ≤ 1.20`；
2. 在这些臂中取 `median_F r_a(F)` 最小者为 nE*；
3. 若无臂满足 → 结论为"**dev 上 38 不可改进**"，直接冻结 (nE,nG2)=(38,12)；
4. 同时记录曲线形状（单调性/极值位置）与 20% FE 检查点，用于论文敏感性图。
