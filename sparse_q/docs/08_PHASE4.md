# 08 — Phase-4 增强轮预注册（2026-10-16，运行前）

依据正式批/失败函数分析（Phase 4）：若 S* 在对 IGWO 或强 PSO 的关键函数族
仍有明显差距，则按以下单一改动择优：

| 标签 | 唯一改动 | 假设（可证伪） |
|---|---|---|
| P4-ref | 无（冻结 S*） | 复跑逐位一致（审计） |
| P4-boost3 | 停滞（≥2% 预算无 gbest 改善）时壳类候选半径 ×3 | H-B：放大"已验证中心 + 成功尺度"的探索半径可在不牺牲末端的前提下提高恢复 |
| P4-steer25 | 25% 的 G1 移动沿"已验证成功位移方向"延长一步（λ=0.5） | H-S：复核用真实成功信息的候选生成提高高价值候选比例 |
| P4-steer50 | 同上，比例 50% | 剂量检验 |
| P4-both | boost3 + steer25 | 组合是否互补 |

门槛：任一增强 vs P4-ref：中位比 ≤0.98 或（≥6/8 且 ≤1.00）；同时报告
恢复窗口概率 / 长停滞占比 / 有用新颖率 / wall-clock。全部负结果保留。
