# 117. Stagnation-Triggered Core Switching P0/P1 预注册

日期：2026-10-23　状态：**P0 失败，停止**

## 机制

主核为 CMA-ES；每 10k 真实 FE 检查一次相对全局最优进展：

`rel=(bestAtWindowStart-bestNow)/max(abs(bestAtWindowStart),1)`。

连续两个窗口 `rel < 5e-4` 时，认为 CMA 进入平台期，剩余预算交给从同一初始池重新启动的 L-SHADE。否则继续 CMA 的协方差状态。

这是一次**在线换核**，不是固定阶段拼接，也不是 pilot 选核：

- 正常函数（尤其 F1/F4/F7）继续完整 CMA；
- CMA 平台期函数（F13/F30）才把剩余预算交给 L-SHADE；
- 切换点由真实 FE 和已验证 best 决定；
- 总 FE 严格等于预算，不转移未评价点。
