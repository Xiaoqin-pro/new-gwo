# 151 — 评价选择规则研究（十五轮）与最终结构决策

日期：2026-10-26
状态：**筛选规则研究已收敛（否定结论）；结构决策已定**

## 0. 结论先行

在“异质候选池（GWO / DiffA / 档案）+ 固定 FE 预算”的结构下，
**没有任何基于距离或来源偏好的评价选择规则能稳定优于无偏随机抽样**。

十五轮对照实验，四种范式，全部失败或等价。但这个否定结论本身
是本文的一个设计依据，不是失败记录。

**最终结构**：M=20 候选 → 按 **4/3/3 评价配额** → 来源内无偏抽样评价 10 个。

## 1. 为什么之前的筛选实验都有混淆

早期实验中，“随机基线”是在整个 100 候选池上均匀抽样，期望评价数是
G1 5.0 / DiffA 1.2 / E 3.8；而几何筛选强制 3/3/4。
**两者比较的其实是“不同算子预算”，不是“筛选聪明不聪明”。**

直到把**评价配额**与**候选生成**解耦（配额固定 4/3/3，候选数由 M 控制），
才得到干净对比。解耦后的实验（第 13–15 轮）仍然是失败的。

## 3. 机制解释（本文的设计依据）

**几何筛选在单峰/复合上可提速 2–5 倍（U 低至 0.18），在多峰上退化 1.5–2.8 倍。**

原因：

1. **距离准则隐含“离最优近 = 有价值”的假设。** 单峰地形上成立；多峰地形上，
   最有价值的候选恰恰可能远离当前最优（在另一个未探索的盆地）。
2. **多峰搜索需要“持续、无记忆地覆盖所有盆地”。** 任何基于距离的挑选——
   无论选近的还是远的、无论何时切换（阶段化只把 1.75 缓解到 1.50）——
   都会让某个盆地在某一代完全没有候选被评价。无偏随机抽样保证每个候选都有机会。
3. **在异质候选池上，全局筛选等价于改算子权重。** “离 α 最近”几乎只命中 G1
   候选（GWO 本来就向 α 收敛），于是评价预算被系统性地从 DiffA/E 转移到 G1，
   而 G1 的单次评价效率最低（17.1 改进/100 次评价，对比 DiffA 82.2、E 64.8）。

## 4. 最终结构（已冻结）

```
每代：
  1. 生成 M = 20 个候选
       G1（GWO 移动）      8 个
       DiffA（差分槽位）   6 个
       E（档案槽位）       6 个
  2. 按固定评价配额抽 10 个真实评价
       G1 4 个 / DiffA 3 个 / E 3 个
       每个来源内部均匀随机抽取
  3. 原子提交 + 档案准入（真实评价、严格更优、空间分离 ≥2% 跨度）
```

**为什么配额 4/3/3 比槽位 50/12/38 好讲**：

- 50/12/38 是“生成多少个候选”，需要解释为什么是这些数
- 4/3/3 是“10 次真实评价怎么分配”，直接对应资源受限的预算分配问题
- 两个创新机制各占 3/10（30%），消融时对比强度对称

**为什么消融可行**：消融替换的是**生成器**，不是**评价名额**。
去掉 DiffA 时，它的 3 个名额转给 G1，总评价数恒为 10。
评价预算恒定，因此归因干净。
