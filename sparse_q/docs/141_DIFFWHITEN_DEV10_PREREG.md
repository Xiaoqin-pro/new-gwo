# Diff-GWO 白化差分 dev10 预注册（2026-10-24）

## 问题（已由 confirm30 铁证确立）

全差分算子（`x_i + F(α−x_i) + F(x_r1−x_r2)`，F=0.5，替换 G1 领导聚合）：
- **巨大且 30/30 种子稳定的收益**：F1 0.003×、F3 0.03×、F18 0.16×、F30 0.30×；
- **旋转/病态函数灾难**：F9 258×、F6 6.2×、F8 2.2×、F5 1.8×、F26 1.9×（28–30/30 种子稳定恶化）。

根因假设：差分方向 `x_r1−x_r2` 是**坐标对齐的**；旋转函数（F6/F8/F9）的景观主轴与坐标轴错位，差分方向与主轴不匹配，破坏 GWO 的收敛结构。聚合+差分（op5）能部分修复（F9 54→12×）但丢失 F1 收益（1.01 无净收益），说明不能退回聚合。

## 机制：白化差分（covariance-whitened differential）

保持 op2 的差分公式，但对差分向量做**协方差白化**：

```
dv = x_r1 − x_r2
dv_w = B · diag(1/√λ) · B' · dv        // B: 种群上半部协方差 C 的特征向量, λ: 特征值
xg = x_i + F·(α − x_i) + F·dv_w
```

- 可分离函数（F1/F3/F18）：种群协方差≈对角，白化≈逐维缩放，几乎不影响差分 → 保留巨大收益；
- 旋转函数（F6/F8/F9）：白化把差分方向旋转到主成分轴并按尺度归一，自动对齐景观主轴 → 修复灾难；
- 每 10 代重建一次白化缓存（`whEvery`），计算开销 O(D^3) 每 10 代一次，可忽略；
- 与 E（已验证档案）正交：差分负责 G1 更新方向，E 负责多区域候选来源 → "差分 + E"组合故事。
