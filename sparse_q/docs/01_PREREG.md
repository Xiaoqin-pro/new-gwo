## 1. 阶梯与门槛（单因素）

| 批次 | 变体 | 唯一变化 | 门槛 |

### SCREEN1 门槛（种子 3001:3005，D30/30k）

* **G_S1（稀疏骨架可用性）**：S1 vs GWO 中位比值 ≤ 1.00 且函数胜负 ≥ 4/8。
  不满足 → 检查稀疏参数（M/K），仍不过则报告"稀疏+随机不可用"。
* **G_S2a（筛选有效性）**：S2 vs S1 中位比值 ≤ 0.98 或（胜负 ≥ 6/8 且比值 ≤ 1.00）。
* **G_S2b（H1：早期与简单多峰）**：S2 vs S1 在 FE20k 中位比值 ≤ 0.98；
  且在简单多峰子集（F4,F6,F9）函数均值胜负 ≥ 2/3。
* 晋级：G_S2a 与 G_S2b 同时满足 → S2 进入 SCREEN2；否则先检查 S2 筛选
  实现（一次修正机会，仍不过→回退 S1 或报告失败）。

### SCREEN2 门槛（在 S2 骨架上扫固定配额）

* **G_S3**：最优固定配额 vs S2(fixed 0.5)：中位比值 ≤ 0.99 或胜负 ≥ 6/8；
  否则维持 0.5。记录全部三个配额（含负面）。

### SCREEN3 门槛（S4 随机配额、S5 Q 学习）

* **G_S4**：S4 相对 S3-best 的中位比值 ∈[0.95,1.05]（随机配额应大体中性；
  若随机配额意外大胜，说明是"抖动"效应而不是学习，需要额外解释）。
* **G_S5（H3）**：S5 vs S3-best 与 S5 vs S4 同时满足：中位比值 ≤ 0.99
  或（胜负 ≥ 6/8 且比值 ≤ 1.00）。同时报告动作占比/状态访问/窗口奖励；
  若某动作占比 > 90% → 标注退化。不满足 → 删除 Q（只保留固定配额），
  并保留负结果；**S6（Q 调 K）只在 G_S5 通过后才开发**。
* Q 的奖励、ε、α、γ 使用固定预注册值（α=0.1, γ=0.9, ε:0.3→0.05,
  窗口 500 真 FE, 奖励=clip(rel-Δgbest,0,1)+0.1×记功评价比例），
  不与 K 扫描同时进行。

### FINAL 双轴门槛（D=50，29 函数，30 种子）

* **A（探索效率）**：S* vs B0（冻结 ANGWO）在 FE20k 中位比值 ≤ 0.98，
  且简单多峰（F4–F10）中位比值 ≤ 0.98；有用新颖率均值 ≥ B0。
* **B（真实停滞恢复）**：S* 的 RecoveryProbWindow ≥ B0 + 0.05（绝对值），
  且 LongStagShare ≤ B0 − 0.03。低于门槛逐项如实报告"未达"。
* 亦报告 vs 标准 GWO、IGWO、HIDMS/HCLPSO/DMS/SAQ、RASE-GWO（协议匹配时）。
* 中止规则：位置/适应度污染、FE 漏洞、基线修改 → 立即停机；连续三批无
  预注册增益 → 停止该分支；最终集仅冻结后运行一次。
