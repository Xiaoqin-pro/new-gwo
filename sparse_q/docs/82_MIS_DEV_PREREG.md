# 82. MIS-GWO（多子群稀疏 GWO）dev 预注册（复用冻结臂）

日期：2026-10-23　状态：**运行前冻结**

## 1. 机制（论文口径：我们提出……）

**MIS-GWO（Multi-Island Sparse GWO）**：把 N=50 只狼划分为 `nIsl` 个共演化的子群，
每个子群拥有自己的 α/β/δ 领导者三元组，用于生成**本子群**的 G1 候选；
外部候选（填充路线与已验证档案路线 E）按轮转归入各子群并更新其领导者；
每 `T` 代执行一次**精英迁移**：把子群 k 的最好已评价狼复制到子群 k+1 的最差槽位
（位置与适应度都已真实验证，**零额外 FE**），并插入接收子群的领导者；
共享档案 E、STEER、随机筛选、M=100、K=10、真实 FE=100k 全部不变。

**设计动机（先验，不依赖任何实验发现）**：
单种群 GWO 的三个领导者容易塌缩到同一盆地，G1 路线因此丢失盆地级多样性；
多子群结构维持多条独立搜索轨迹，共享的已验证档案在子群间传递知识，迁移注入已验证的多样性。
（另注：论文的 17 算法对比中排名靠前的 HIDMS-PSO/DMS-PSO/HCLPSO 均为多群体方法。）

`nIsl=1` 与冻结终版 **逐位一致**（`tests/test_mis_contract.m` 已断言）。
