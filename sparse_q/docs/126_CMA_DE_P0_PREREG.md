# CMA-DE5 P0 预注册（2026-10-23）

## 假设

在保持 CMA-ES 全协方差、均值、步长和真实 FE 计费不变的前提下，每代用约 5% 的 DE 位移改写高斯提议的中心，可把来自已验证种群的差分方向注入主协方差学习轨迹，从而在复合/多盆地函数上改善收敛，同时不破坏单峰函数。

## 实验协议

- CEC2017，D=50，N=50，100k 真实 FE，K=10 配置不参与 CMA 主核。
- 8 函数：F1/F4/F7/F10/F13/F20/F24/F30。
- 5 个全新种子：4141–4145。
- 4 个 worker，160 次运行。
- 臂：
  - A-CMA：普通 CMA-ES。
  - B-DE5：5% DE 中心注入。
  - C-PermutedDE5：与 B 完全相同数量/幅度的 DE 步，但在候选内随机置换坐标，破坏方向对齐，用于方向信息对照。
  - D-Random5：同样 5% 候选改为均匀随机中心，用于一般探索对照。
  - E-jSO：强外部基线。

## 预先固定的晋级门槛

主机制 B 必须同时满足：

1. `B/A` 中位误差比 ≤ 0.98，至少 6/8 函数胜出，且 >1.20 的函数不超过 1 个。
2. `B/E`（对 jSO）中位误差比 ≤ 0.90，至少 6/8 函数胜出，且 >1.20 的函数不超过 1 个。
3. `B/C` 中位误差比 ≤ 0.98，并且 B 的胜函数数至少比 PermutedDE5 多 2 个，证明 DE 方向本身有效。
4. `B/D` 中位误差比 ≤ 0.98，证明不是任意探索都有效。
5. 运行时间 `B/A` ≤ 1.25。

若未通过，记录为 STOP，不进入 15×10 P1，也不进入正文；不通过后不改变门槛回看结果。

## 消融解释目标

- A vs B：跨源中心注入是否有效。
- B vs C：DE 方向对齐是否比同等幅度但打乱坐标更有效。
- B vs D：差分信息是否优于一般探索。
- B vs E：相对强 DE 基线是否仍有优势。
