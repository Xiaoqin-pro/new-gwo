# 40. TSD-R 三臂确认预注册

## 0. 前置条件

TSD-R P0 已通过全部门槛：触发事件识别出后续三次真实评价改善率更低的轨迹，恢复候选落入 E 覆盖区域仅 21.17%。

本轮只确认主动恢复是否带来最终性能收益。

## 1. 三臂与复用

| 臂 | 机制 | 来源 |
|---|---|---|
| A | 冻结 G1+E | `ablcore_20261017_062209` 的 A2-G1E，870 条，已逐位复现 |
| B | TSD-base | `tsd_confirm_bc_20261021_101017` 的 C-TSDbase，870 条，已逐位复现 |
| C | TSD-R | 本批新跑 870 条 |

A/B/C 全部使用相同函数、种子和 100,000 FE：

- 29 函数：F1、F3–F30；
- 种子：3071–3100；
- 配对初始化协议：`initSeed=261013000+fid*10000+seed`；
- G2 关闭，12 个槽位由标准 GWO 候选受控填补；
- E 配额 38，K=10，M=100。

A 与 B 的复用均通过逐位复现审计。

## 2. TSD-R 主动规则

在 TSD-base 的 P/Z 状态上，对每个槽位维护真实评价连续未刷新 P 的次数 \(c_i\)，并定义：

\[
g_i=\frac{\max(0,f(Z_i)-f(P_i))}{\mathrm{IQR}(\{f(Z_j)\})+\epsilon}.
\]

在生成下一次 G1 候选前，若：

\[
c_i\ge3\quad\text{且}\quad g_i\ge1,
\]

则执行 \(Z_i\leftarrow P_i\)，同步 \(f(Z_i)\leftarrow f(P_i)\)，并清零 \(c_i\)。不改变方向公式、评价预算、E 配额或档案规则。

## 3. 主要假设与门槛

### H1：C 对 A 非劣

- 函数级配对中位误差比 95% bootstrap CI 上界 <1.05；
- 最多 2/29 个函数中位比 >1.20，且没有函数 >1.35；
- 运行时间比 C/A ≤1.15。

### H2：C 对 B 有预注册改善

- C/B 函数级中位误差比 ≤0.98；
- 至少 18/29 个函数获胜；
- 没有函数中位误差比 >1.20；
- 运行时间比 C/B ≤1.15；
- 复杂函数族（简单多峰、混合、组合）不能被单峰函数的收益替代：至少两个复杂函数族 C/B 中位比 <1.00，且没有复杂函数族中位比 >1.05。

主比较的函数级 Wilcoxon 结果使用 Holm 校正；比较级检验也对 C/A、C/B 两个主比较做 Holm。

## 4. 判定规则

| H1 | H2 | 判定 |
|---|---|---|
| 通过 | 通过 | `CONFIRM_TSDR_SECOND_CONTRIBUTION` |
| 通过 | 不通过 | `TSDR_NONINFERIOR_ONLY` |
| 不通过 | 通过 | `TSDR_GAIN_OVER_BASE_ONLY` |
| 不通过 | 不通过 | `STOP_TSDR_CONFIRMATION` |

只有 `CONFIRM_TSDR_SECOND_CONTRIBUTION` 才能把 TSD-R 写成第二项已确认机制；其他结果作为设计边界或补充消融。

## 5. 禁止事项

- 不扫描连续失败次数 3 或 IQR 阈值 1；
- 不删除函数或只报告有利函数族；
- 不改变 A/B/C 的 FE、E 配额或筛选规则；
- 不覆盖 `main`、冻结 `SGWO.m` 或已有正式结果。
