# 27. AMC 双因素预注册：档案信用 × GWO 移动幅度控制

## 0. 背景

前一轮已经得到两个独立信号：

- Identity-Credit 修正了档案中心身份和信用归属，在 8 函数 P1 上相对 V1 中位比 0.961、6/8 胜；
- ENAC 相对 V1 中位比 0.939、8/8 胜，但没有稳定超过 Identity-Credit，因此不能预先认定曝光归一化有独立贡献。

本分支把研究拆成两个模块，做一次 5 臂双因素筛选：

- 模块 A：档案信用机制；比较冻结 V1、Identity-Credit、ENAC；
- 模块 B：GWO 核心位置更新；在 G1 领导狼建议上加入移动幅度系数 \(\gamma_t\)；
- 模块 A 与 B 可以独立验证，最后再检查组合表现。

相关已有工作：

- Meidani et al., *Adaptive grey wolf optimizer*, 2022, DOI `10.1007/s00521-021-06885-9`；
- Zhang & Cai, *Adaptive dynamic self-learning grey wolf optimization algorithm*, 2024, AIMS Math, 开放 PDF；
- 这两项工作说明适应度历史/成功率自适应步长已有研究。本文不声称“首次自适应步长”，只检验在 SGWO 稀疏真实评价框架中的具体适配。

## 1. 机制 B：自适应移动幅度控制

### 1.1 更新接口

标准 GWO 的三个领导狼建议位置：

\[
Z_i=\frac{X_{i,\alpha}+X_{i,\beta}+X_{i,\delta}}{3}
\]

原公式直接令：

\[
X_i^{new}=Z_i
\]

本分支只引入移动幅度系数：

\[
X_i^{new}=X_i+\gamma_t(Z_i-X_i)
\]

- \(\gamma_t=1\) 时与原公式逐位一致；
- \(\gamma_t>1\) 时沿原方向扩大移动；
- \(\gamma_t<1\) 时缩短移动；
- 本分支先只允许 \(\gamma_t\in[1,2]\)，即只做“停滞时扩大步幅，恢复后回到标准步幅”。

### 1.2 反馈样本

只使用真实评价过的 G1 候选：

- 一轮中所有被选中的 `src==1` 候选；
- 成功定义为候选严格优于其生成时的父狼 `recImp`；
- 未评价候选、G2、E 不进入反馈；
- 不增加真实 FE，不重新评价历史点。

### 1.3 \(\gamma_t\) 控制规则（固定参数，不扫描）

- \(\gamma_0=1\)；
- 有效反馈窗口 `W=10` 轮；
- 每轮计算 G1 成功率 \(p_t=s_t/n_t\)；
- 最近窗口平均成功率 \(p_{win}\)；
- 停滞触发复用冻结参数 `stagnThresh=max(500,round(0.02B))`；
- 控制规则：
  1. 如果本轮出现严格全局最优改善：
     \[
     \gamma\leftarrow\max(1,0.90\gamma)
     \]
     若 \(\gamma<1.05\)，直接置为 1。
  2. 否则，如果 \(FE-lastGB\ge stagnThresh\)、有效反馈轮数不少于 10，且 \(p_{win}<0.2\)：
     \[
     \gamma\leftarrow\min(2.0,1.10\gamma)
     \]
  3. 其他情况保持 \(\gamma\) 不变。
- \(\gamma\) 在本轮候选生成时使用；根据本轮真实评价更新后，供下一轮使用。

### 1.4 不改的部分

- G1 的三个领导狼建议公式、A/C 随机数结构和最终位置接口；
- G2 的 Alpha 壳、E 的单中心壳和双中心线段；
- 档案插入、替换、中心选择（除 A/B 本身已有的信用差异）；
- 候选池 M=100、K=10、N=50、nG2=12、nE=38；
- 真实 FE 预算；
- 不使用提前停止。

## 2. 5 臂双因素设计

| 臂 | 档案信用 | GWO 更新 |
|---|---|---|
| A | Identity-Credit | 标准 \(\gamma=1\) |
| B | ENAC | 标准 \(\gamma=1\) |
| C | Identity-Credit | AMC \(\gamma_t\) |
| D | ENAC | AMC \(\gamma_t\) |
| E | 冻结 V1（槽位累计信用） | 标准 \(\gamma=1\) |

- 所有臂使用相同函数、种子、初始化、候选池、真实 FE 和档案参数。
- A/B/C/D 使用同一个 `SGWO_AMC.m`，只有 `enacMode` 和 `amcOn` 不同。
- E 使用冻结 `SGWO.m`。

## 3. P1 实验

- CEC2017，D=50；
- 15 个函数：
  - 单峰：F1、F3；
  - 简单多峰：F4、F7、F10、F11；
  - 混合：F13、F14、F16、F18、F20；
  - 组合：F22、F24、F26、F30。
- 种子：3176–3185；运行前已扫描历史 CSV，未发现使用；
- 真实 FE：30,000；
- MATLAB local 4 worker；
- 冒烟：F1、seed 3987、3,000 FE。
- 规模：5 臂 × 15 函数 × 10 种子 = **750 次运行**。

## 4. 晋级门槛

### 4.1 主公式门槛

C 相对 A：

1. 跨函数中位误差比 ≤0.98；
2. 至少 11/15 个函数获胜；
3. 没有函数中位误差比 >1.20；
4. 平均运行时间 C/A ≤1.15。

D 相对 B：

1. 跨函数中位误差比 ≤0.98；
2. 至少 11/15 个函数获胜；
3. 没有函数中位误差比 >1.20；
4. 平均运行时间 D/B ≤1.15。

只有 C 和 D 都通过，才能声称 AMC 在两种信用机制上都有独立收益。只有一项通过，只支持对应基线。

### 4.2 信用机制参照

B 相对 A：用于检查 ENAC 曝光归一化是否在本次同批新种子、15 函数上超过 Identity-Credit。数值门槛同样为 0.98 / 11/15 / 1.20。

如果 B/A 不通过，不得把 ENAC 曝光归一化写成独立有效机制。

### 4.3 交互检查

D 相对 C：检查 AMC 与 ENAC 是否产生正向交互。仍使用 0.98 / 11/15 / 1.20 门槛。

即使 D 胜出，也不能自动证明 ENAC 归一化有效；必须同时看 B/A。

### 4.4 过程证据

必须报告：

- \(\gamma_t\) 随真实 FE 的变化；
- 扩张/收缩事件次数；
- G1 评价数、成功数、成功率、每 1,000 FE 的改进次数；
- 停滞长度与恢复指标；
- Identity/ENAC 权重集中度、中心评价数与成功率；
- 运行时间与失败记录。

## 5. 淘汰规则

- C/A 与 D/B 均不通过：停止 AMC，不扫描窗口、成功率阈值、扩张/收缩因子或 \(\gamma\) 上下限。
- 只有 C/A 通过：只支持 Identity-Credit + AMC。
- 只有 D/B 通过：只支持 ENAC + AMC，但仍需单独解释 ENAC 归一化。
- C/A 与 D/B 都通过：才进入 29 函数、D=50、100k FE、30 个全新种子的 P2。
- 不使用 3176–3185 作为最终测试种子。
- 不把 A/B 已有的 8 函数结果与新 15 函数批次拼接；本批全部重新跑。

## 6. 学术边界

AMC 的自适应步长思想与已有 AGWO、ASGWO 等工作有重叠。本文的检验边界是：

> 在稀疏真实评价框架中，只用已评价 G1 候选的成功率反馈，控制 GWO 领导狼建议的移动幅度，是否在 Identity-Credit 和 ENAC 两种档案信用机制上都能独立改善最终性能。

不能把自适应步长本身宣称为首次提出。
