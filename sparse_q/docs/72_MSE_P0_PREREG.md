# 72. MSE（多尺度精英壳）P0 被动审计预注册

日期：2026-10-22（本地客户端时区）　状态：**运行前冻结**

## 1. 机制与研究问题

E 路线的单中心壳目前用**单一全局尺度**：`L_t=max(median(成功步长), 0.01·S)`，`σ_t=L_t·sqrt(3/D)`，
候选 `y=c+σ_t(0.5+u)(2v−1)`。一个尺度无法同时服务"盆地内精修"和"邻近盆地探索"。
MSE 只把单中心壳的尺度重分配为 **{0.5σ, σ, 2σ} 的均值保持混合**（概率 1/3, 1/2, 1/6，因
`E[m]=1`，平均半径不变、只有离散度增大：RMS 乘子 sqrt(E[m²])=1.118）。
匹配 RMS 的单尺度对照 C（常数乘子 k=1.118，单峰形状）用于把"多尺度形状"与"单纯步长更大"分开。

**不改**：E 的准入/删除/容量/分离/信用、双中心插值分支、STEER、筛选、接受规则、M=100、K=10、真实 FE。
`mseMode='none'` 与 `SGWO_STEER3` **逐位一致**（`tests/test_mse_contract.m` 已断言）。

## 2. P0 设计（被动，8 函数 × 5 新种子 3489–3493 × 100k FE = 40 次）

`mseMode='audit'`：用独立随机流 `sMse=seed+777777` 抽取尺度类别并计算反事实候选，
**只记录、不改变 Y**；审计轨迹必须与冻结终版逐位一致。
记录：每类候选数、每类平均归一化位移（||y−c||/span）、每类边界裁剪率、每类被真实评价的候选数与比例。

## 3. 预注册门槛（先冻结，后运行）

1. **完整性**：audit 轨迹与冻结终版逐位一致（合约测试 + 批次级检查）；
2. **可区分性**：≥6/8 个函数满足 `median(粗类位移)/median(基准类位移) ∈ [1.6, 2.1]` 且
   `median(细类位移)/median(基准类位移) ∈ [0.40, 0.60]`；
3. **非退化**：≥6/8 个函数粗类候选的边界裁剪率 ≤ 0.30（避免"粗尺度全被裁到边界"）；
4. **可到达**：≥6/8 个函数中每一类的被评价比例 ≥ 0.05（随机筛选下期望≈0.10）。

不通过 → **停止 MSE 线**，不扫描尺度集合、混合比例或对照常数。
