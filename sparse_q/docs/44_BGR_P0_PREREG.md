# 44. BGR P0 被动审计预注册

## 0. 机制定义

BGR（Boundary-Geometry Repair）只改变 G1 候选越界后的修复方式：

- 当前冻结版本使用逐维截断 \(x_d'=\min(\max(x_d,l_d),u_d)\)；
- BGR 候选使用确定性反射映射，把越界坐标按搜索区间宽度反射回边界内；
- 不改变 GWO 公式、E、筛选、候选总数 M=100、K=10 或真实 FE。

P0 不执行反射，只审计冻结版本的截断失真机会。

## 1. 审计内容

- G1 候选中至少一个坐标越界的比例；
- 越界坐标占全部坐标的比例；
- 截断前后归一化位移的中位数、均值和 P90；
- 早/中/后期越界比例；
- 审计模式与冻结 G1+E 的 Trace、Best、FE 逐位一致。

## 2. 实验协议

- CEC2017，D=50；
- 8 个函数：F1、F3、F4、F7、F10、F13、F20、F30；
- 种子：3296–3300（运行前扫描历史 CSV 确认未使用）；
- 真实 FE：100,000；
- 1 个审计臂 × 8 函数 × 5 种子 = **40 次运行**。

## 3. P0 通过条件

同时满足：

1. 至少 6/8 个函数中，至少 4/5 个种子的 G1 越界候选比例 ≥20%；
2. 至少 6/8 个函数中，截断位移中位数 >0.01（按搜索空间对角线归一化）；
3. 现象覆盖早/中/后期，不能只出现在单一阶段；
4. 审计模式 Trace、Best、FE 逐位一致。

未通过则停止 BGR，不进入主动消融。

## 4. 如果 P0 通过

三臂消融：

- A：冻结 G1+E，原有截断；
- B：只对 G1 越界候选使用反射修复；
- C：只对 G1 越界坐标随机重置，作为匹配对照。

保持相同初始种群、M=100、K=10、100,000 FE、E 规则和筛选方式。B 必须同时优于 A 和 C，才能支持“反射保留几何信息”是关键原因。
