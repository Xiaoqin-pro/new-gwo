# 79. 分配结构诊断 P0 预注册（E 路线内部分支价值 / 档案覆盖 / 时间趋势）

日期：2026-10-23　状态：**运行前冻结**

## 1. 背景与候选机制

冻结实现把 E 路线的 38 个名额按 `mod(j,2)` **固定 1:1 交替**分给两支：
单中心壳（围绕一个档案中心加壳噪声）与两中心插值（两个中心之间的线段 + 小扰动）。
3k FE 冒烟诊断（1 函数 1 种子）显示两类的**严格价值**差异极大：
单中心壳 558 次评价中 0 次全局最优改进、入库率 1.6%；两中心插值 553 次中 2.53% 全局最优改进、入库率 26.9%。
若该不对称在正式协议下成立，则"**E 路线的内部分配**"是一个从未被验证、且可干净消融的设计变量
（与已关闭的 nE 槽位配比、档案规则、信用、壳半径都不同）。

## 2. P0 设计（被动，8 函数 × 5 新种子 3554 之前不可用 → 用 3564–3568 × 100k FE = 40 次）

`src/SGWO_DIAG.m`：与 `SGWO_STEER3` **逐位一致**（合约测试 `tests/test_diag_contract.m`），只增加记账：

- 类别：1=G1、2=填充(src∈{2,4})、3=E 单中心壳、4=E 两中心插值；
- 每类每 FE 十分位：评价数、**全局最优改进数（严格、跨类可比）**、**档案插入/刷新数**、种群替换数；
- 档案覆盖：每个槽位生命周期内获得的真实评价次数（直方图、零评价比例、均值）；
- 档案相对质量（每 1000 FE 采样，按十分位记录）。

## 3. 门槛（运行前固定）

- **G-c′（内部分支价值不对称，主前提）**：≥6/8 个函数满足
  `GBrate(E-2centre) ≥ 2 × GBrate(E-shell)` **且** 该函数内 E-2centre 的全局最优改进中位次数 ≥2。
- **G-b′（覆盖不足）**：≥6/8 个函数满足"零评价槽位生命周期比例"中位 ≥0.30。
- **G-i′（时间趋势，报告项，不作门槛）**：E 两类合计的 GB 率在后三个十分位 / 前三个十分位；档案相对质量前后对比。

- 若 G-c′ 成立 → 实现并预注册"E 内部分配重构"P1（4 臂：A 冻结 1:1 / B 1:3 / C 0:1 全插值 / D 3:1 反向对照），
  以标准门槛判定；
- 若仅 G-b′ 成立 → 先做覆盖类机制的影子评估，不直接实现；
- 若 G-c′ 与 G-b′ 都不成立 → 停止分配结构线。
