## 1. 机制

保留 G1+E+STEER、档案、K、N、M、FE。G1 的 50 只狼分成：
- 30 只完整维 GWO+STEER 开发狼；
- 20 只协同子空间探索狼：每代随机选 15/50 维，只在这些维上使用标准 GWO 更新，
  其余 35 维保持父狼坐标；STEER 后再恢复非子空间坐标。

`cssMode='off'` 与冻结 `SGWO_STEER3` 逐位一致。该机制改变的是搜索表示，
不是替换 G1、不是改评价预算、不是另一个全局进化算子。
