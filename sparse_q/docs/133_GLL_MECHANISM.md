# GLL：Graph-Localized Leadership for GWO

## 1. 问题

标准 GWO 的 α/β/δ 完全由全局适应度前三名决定。随着搜索推进，三只领导狼通常落入同一个吸引域，导致所有 ω 狼被同一个方向持续压缩；E 档案虽然提供多区域候选，但不改变“领导如何形成”这一核心结构。

GLL 不替换 GWO 领导方程，也不改变 α 的全局地位。它只改变 β/δ 的来源：每只狼从自己的状态图中选择一个局部邻域，把邻域内已验证的最优两只狼作为 β_i/δ_i。

## 2. 状态图

对每只已验证狼 i 定义四个归一化特征：

- 适应度排名 `r_i`；
- 距上次改善的停滞年龄 `s_i`；
- 到全局 α 的归一化距离 `d_i^α`；
- 到当前群体中心的归一化距离 `d_i^c`。

按维度做 z-score，得到节点特征 `h_i ∈ R^4`。在特征空间建立 kNN 图（默认 k=20），邻域记为 `N_i`。每 50 代重建一次图，降低计算开销。

## 3. 局部领导

- α 仍为全局最优；
- `β_i = argmin_{j∈N_i} f_j`；
- `δ_i = argmin_{j∈N_i\{β_i}} f_j`；
- 保持标准 GWO 方程：

```text
X1 = α       − A1 · |C1 · α       − X_i|
X2 = β_i     − A2 · |C2 · β_i     − X_i|
X3 = δ_i     − A3 · |C3 · δ_i     − X_i|
X_i' = (X1 + X2 + X3) / 3
```

E、STEER、K=10、M=100、筛选、接受规则和真实 FE 计费均不变。

## 4. 为什么不是 LLT

LLT 使用固定环形窗口，局部领导的空间位置由狼的编号决定，且完全替代全局领导；GLL 使用由进化状态和空间位置共同决定的动态特征图，并保留全局 α。GLL 的局部化是“状态相似个体之间传播领导信息”，不是固定拓扑。

## 5. 消融设计

- **Global**：标准全局 α/β/δ；
- **EuclidKNN10**：只用欧氏距离的局部 β/δ；
- **RandLocal20**：同 k=20 的随机局部邻居；
- **GLL20**：完整状态图局部领导；
- **GLL20-Blend0.8**：全局领导与局部领导按 0.8 混合；
- **E off/on**：检验 GLL 与已验证档案的作用对象是否正交。

## 6. 预期故事

GLL 的核心叙事不是“再加一个扰动”，而是：

> 全局领导负责收敛压力，局部状态图负责领导信息的空间分化；E 提供多区域已验证候选，STEER 提供等长方向覆盖。三者作用在不同层级：候选来源、领导形成、方向扰动。

如果确认级成立，最终算法可表述为：

**Graph-Localized Verified Archive GWO (GL-VAST-GWO)**

其贡献为：

1. 状态感知的局部领导图，用于缓解全局 α/β/δ 塌缩；
2. 已验证多区域档案，用于候选生成；
3. 等长方向 STEER，用于候选方向覆盖；
4. 严格真实 FE 计费与可复现消融。

## 7. 已知工程代价

D=50、N=50 时，GLL20 的运行时间约为 Global 的 1.39×；主要来自特征图构建和邻域排序。图缓存周期 10/50/100 的行为接近，当前冻结在 50 代。
