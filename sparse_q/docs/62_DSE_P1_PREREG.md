## 1. 机制（在文件 2 原案上按 P0 证据简化）

- **触发（双停滞）**：`FE − FE_lastGB ≥ τ` 且 `FE − FE_lastArcImp ≥ τ`，`τ=max(500,0.02B)=2000`；
- **动作**：门控开启期间，每代把 **1 个已选评价名额**（第 10 个，按池索引排序后的最后一个）替换为逃逸候选
  `x_e = Reflect(α + ρ·span·c·v)`，其中 `v` 单位随机方向、`ρ=0.05`；
  - `cauchy`：`c ~ Cauchy(0,1)`（重尾）；
  - `gauss`（匹配对照）：`c ~ N(0, 1.4826²)`（中位 |c| 与 Cauchy 相同）；
- **预算**：逃逸评价总数 ≤ `dseCapFrac=5%` 的总 FE（本 P0 显示实际用量约 0.1%–1.5%，是安全上限）；
- **无脉冲上限、无 FE≥50% 门**（原案中的 20 代脉冲与该门在 P0 证据下被删除：停滞窗口本身很长）；
- 其余全部冻结：候选池、筛选、E 的规则、档案准入、接受规则、FE 计费；逃逸候选走**既有外部候选路径**
  （真实评价后才可能进入种群/档案），使用独立随机流。

合约测试：`dseMode='none'` 与 `SGWO_ABLATION` **逐位一致**；20k 冒烟中 cauchy 用 202 次逃逸（1.01% 预算，
首次 FE 6780，51 次进入种群），gauss 用 305 次。

## 3. 预注册门槛

- **H1（在已确认 STEER 之上的增量）**：D/B 中位误差比 ≤0.98；≥11/15 个函数获胜；无函数 >1.20；运行时间比 ≤1.15；
- **H2（独立于 STEER）**：C/A2 同样门槛；
- **H3（重尾归因，报告）**：D/E 的中位比与胜负数；若两者基本持平（|中位比−1|<2% 且胜 ≤8/15），
  则不能把收益归因于 Cauchy 重尾，只能归因于"停滞期多一个远距离候选"；
- **过程证据（报告）**：门控开启率、逃逸次数与占比、逃逸候选进入种群/档案的比例、首次触发 FE、早期 FE 检查点。

## 4. 判定

- H1 与 H2 同时通过 → `PROMOTE_DSE`：进入 29×30 确认（复用 A2/B + 新跑 D/E）；
- 仅 H1 通过 → 只能声称"与 STEER 存在交互"，需要确认阶段显式检验两因素交互，不得单独宣称 DSE；
- 仅 H2 通过 → 说明 DSE 在无 STEER 时有独立价值，但与当前最佳组合不兼容（保存为设计边界）；
- 全部不通过 → 停止 DSE；不再扫描 ρ、τ、预算上限或候选替换位置，逃逸方向整体停止。
