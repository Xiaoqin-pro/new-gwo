# SVAD-GWO：算法结构与参数说明

## 名称

**SVAD-GWO**
Sparse-evaluation Grey Wolf Optimizer with a Verified Archive and Differential Search
融合已验证精英档案与差分搜索的稀疏评价灰狼优化算法

## 结构（三层候选来源，共享同一真实评价预算）

```
每代：
  1. 生成 M = N + nG2 + nE 个廉价候选（不消耗真实 FE）
       (1) 领导引导狼群  N = 50
           标准 GWO 三领导聚合；以概率 p 叠加等长随机方向扰动
       (2) 差分槽位  nG2 = 12   ← DiffA
           y = x_r1 + F(t)·(α − x_r1) + F(t)·(x_r2 − x_r3)
           r1,r2,r3 互异，取自「狼群 ∪ 已验证档案」联合池
           F(t) = F0 − (F0−F1)·max(0, (t−tc)/(1−tc)),  t = FE/FE_max
       (3) 已验证档案槽位  nE = 38   ← VMA
           单中心壳（按档案信用加权选中心）
           双中心线段（两个已验证精英之间插值）
           壳半径 σ 由近期已验证成功步长的中位数自适应确定
  2. 从 M 中均匀随机抽 K = 10 个做真实评价（严格计费）
  3. 原子提交
       领导引导候选：狼总是移动，改善才计入信用
       差分/档案候选：仅当优于当前最差狼才替换
  4. 档案准入：真实评价 + 严格更优 + 空间分离（≥2% 搜索跨度）
```

## 参数（全部为固定实验设置，非逐函数调节）

| 参数 | 值 | 说明 |
|---|---:|---|
| N | 50 | 狼群规模（领导引导候选数） |
| nG2 | 12 | 差分槽位数 |
| nE | 38 | 档案槽位数 |
| M | 100 | 每代候选池（N+nG2+nE） |
| K | 10 | 每代真实评价数（稀疏评价强度） |
| F0 | 1.0 | 差分尺度初值 |
| F1 | 0.3 | 差分尺度终值 |
| tc | 0.7 | 收缩起始位置（预算比例） |
| p | 0.5 | 方向扰动触发概率 |
| λ | 0.5 | 扰动长度（占 G1 步长比例） |
| 档案容量 | 24 | 已验证精英上限 |
| 分离阈值 | 2% | 档案准入的空间分离要求 |

以上 12 个参数在开发集（15 函数 × 10 种子）上一次性确定，并在独立确认集（29 函数 × 30 种子）上验证；不存在逐函数或逐阶段的手工调整。

## 三个机制的逻辑（论文表述）

1. **稀疏评价纪律（Sparse evaluation）**
   每代只对 K=10 个候选做真实评价；未评价候选不得参与排序、领导更新或档案准入。

2. **已验证精英档案（VMA）**
   只保存真实评价过、严格更优、空间分离的解；用单中心壳与双中心线段在其周围生成候选，壳半径由近期成功步长自适应。作用：在有限评价下维持多区域空间信息。

3. **α 引导差分槽位（DiffA）**
   差分候选从「狼群 ∪ 档案」联合池取三点，以 α 为收敛锚点、以池内差分做探索；
   差分尺度随预算收缩，使槽位由探索逐步转为 α 中心精化。

三者作用层级不同：VMA 决定"候选从哪些已验证区域来"，DiffA 决定"如何用已验证信息构造新方向"，稀疏评价决定"谁值得消耗真实评价"。
