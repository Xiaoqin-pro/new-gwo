# GWO 机制设计原则（据老师 SS-RLPSO / RL_GNN_PSO 提炼，2026-10-24）

## 老师两篇的工作结构

### SS-RLPSO（bare_jrnl_new_sample4.pdf，IEEE TEC 风格）
- 主体：PSO，预算只给 20%（稀疏评价，资源受限故事）。
- 组件1 **空间筛选**：每代只评 K=10% 候选（5% 近 gbest 收敛 + 5% 远群体中心探索），主增益来源。
- 组件2 **RL 算子调度**：Q-learning 按 3 阶段 × 3 停滞状态选 4 条算子（exploitation / peer learning / Gaussian / opposition jump），辅助，主要在复杂多模态上有帮助。
- 消融：有/无空间筛选、有/无 RL、灵敏度 ρ。
- 结论：不以最高精度为目标，而是"20% 预算匹敌全预算、1/3~1/2 运行时间"。
- 复杂度：空间筛选 O(N log N + ND)，无 surrogate 的 O(N^3) 负担；每条算子都是 PSO 一行公式。

### RL_GNN_PSO
- 组件1 双策略子群（探索/开发）；
- 组件2 GNN 通信拓扑（节点特征 = 排名/停滞/距离/速度，kNN 建边决定榜样范围）；
- 组件3 RL 邻域规模调节（REINFORCE，动作 K=[10 20 30]）；
- 组件4 排名受限停滞重启（只重启差粒子）。
- 消融：每组件单独开/关。

## 共同特点（我们要学习的"论文配方"）
1. **机制简单**：每个组件是一两行公式（空间筛选 = 距离排序取子集；算子 = 一行速度更新）。
2. **可独立消融**：每个组件都能开/关，消融表干净。
3. **有统一故事**：资源受限 / 拓扑控制 / 自动调节。
4. **对比可复用**：CEC2017，wilcoxon，30 种子。
5. **允许部分函数不改善**：主增益来自大多数函数，复杂多模态是 RL 的补充价值。

## 映射到 GWO（我们已具备 vs 缺什么）
- 已具备：稀疏真实评价 + 空间筛选（E 已验证档案/中心壳/双中心线段）+ STEER（等长方向扰动）+ 真实 FE 计费。
- 缺：一个"GWO 运动更新层"的简单可消融机制（有故事、能做方向/来源对照）。
- 老师的 RL_GNN_PSO 给了我们明确的模板：**拓扑/领导机制的节点特征 + 图 + 邻域**。但我们 GWO 侧的 GLL/FLGWO/SLL/FeatKNN/QTopo 全部被随机局部对照打败（审计结论），说明"局部领导"方向收益不可归因，不能当主贡献。
- 唯一没被随机对照打败的 GWO 内信号：**Diff 差分算子**（20k 四块独立 dev 0.74–0.89，0 尾部）。

## 当前验证中的机制：Diff-GWO（G1 差分算子 + 已验证档案）
- 公式：`x_i + F(α − x_i) + F(x_r1 − x_pool_r2)`，F=0.5（SGWO_STEER3 opNow==2）。
- 待验证（P0 100k FE，seed 4281–4285）：
  - A-Standard（opFixed=1）
  - B-DiffArc（全部 diff，r2 来自狼群∪档案）
  - C-DiffNoArc（r2 只来自狼群）
  - D-DiffShuffle（差分向量坐标置换）
  - E-DiffRandom（r1/r2 换成两个随机点）
- 论文可讲的故事（若通过）："已验证档案差分引导 GWO 更新"——GWO 领导聚合之外，用真实评价过的精英差分方向做候选生成；消融有/无档案、方向 vs 随机。

## 参照老师的两条正交性叙事
- SS-RLPSO：空间筛选（选谁评价）⊥ RL 算子调度（怎么更新）。
- GWO：E（选谁）⊥ Diff 算子（怎么更新）——两层正交、分别消融。
