# 24. SSSA 来源分尺度成功反馈预注册

## 0. 研究问题

冻结 `SGWO.m`、`main` 和已有正式结果保持不变。CD-VACG 已停止。本分支检验一个新的、改动很小的机制：

> 在固定真实评价预算的 GWO 中，把 G2 局部精化路线与 E 单中心档案路线的成功步长历史分开维护，并让两条路线使用各自的来源一致尺度，是否比共享全局尺度更有效？

机制名称：SSSA — Source-Specific Success-Scale Adaptation。

## 1. 当前实现的缺口

当前 `SGWO.m` 使用一个共享成功历史：

```matlab
sig = shellSigma(succ, span, D);
```

其中 `succ` 混合了 G1、G2、E 的成功位移，并且 G2/E 记录的是候选到被替换最差狼的距离，而不是候选相对生成中心的实际位移。

SSSA 只改变尺度估计来源，不改变候选生成结构。

## 2. 两套来源历史

### 2.1 成功定义

候选被真实评价后，满足以下任一条件就算成功：

- `recImp`：候选被接受到种群；
- `arcImp`：候选触发档案插入或替换。

### 2.2 生成时参考位置

- G2 候选：记录生成该候选时的 Alpha 位置；
- E 单中心壳候选：记录生成该候选时的档案中心；
- 位移使用边界裁剪后的实际候选位置：
  \[
  d=\|y_{\text{clipped}}-x_{\text{ref,gen}}\|.
  \]

双中心线段候选不进入 E 单中心尺度历史，因为它的位移包含两个档案中心之间的插值距离。

### 2.3 历史容量与初始化

- 容量：25；
- 最小有效样本数：5；
- 样本不足 5 个：使用 `0.05S` 作为基础步长；
- 下限：`0.01S`；
- 估计公式：
  \[
  \sigma_r=\sqrt{\frac{3}{D}}\max\left(0.01S,\operatorname{median}(\mathcal L_r)\right).
  \]
- 不新增可调参数。

## 3. 候选生成

| 候选来源 | 尺度 |
|---|---|
| G2 Alpha 壳 | \(\sigma_{G2}\) |
| E 单中心档案壳 | \(\sigma_E\) |
| E 双中心线段插值 | 插值系数不变，局部扰动使用 \(0.25\sigma_E\) |
| `alphaSingleE`、`farE`、`ArcN==0` 回退 | 继续使用原 `sigB` |
| G1 | 不变 |

其他全部冻结：

- M=100，K=10，N=50，nG2=12，nE=38；
- 档案插入、替换、空间分离；
- 随机筛选、真实评价计费、领导者更新；
- 接受规则和边界处理。

## 4. 关键对照：SSSA-Swap

如果只比较 V1 和 SSSA，即使 SSSA 获胜，也不能证明“来源匹配”本身有价值；可能只是两套不同尺度有用。

因此增加 SSSA-Swap：

- 仍然分别维护 \(\sigma_{G2}\) 和 \(\sigma_E\)；
- 但使用时交换：G2 使用 \(\sigma_E\)，E 使用 \(\sigma_{G2}\)；
- 候选生成、历史更新、选择、FE 和其他设置与 SSSA 完全一致；
- 唯一区别是尺度是否正确匹配来源。

## 5. P1 实验

- CEC2017，D=50；
- 函数：F7、F10、F13、F16、F18、F22、F24、F30；
- 种子：3141–3150；运行前已扫描历史 CSV，未发现使用；
- 真实 FE：30,000；
- MATLAB local 4 worker；
- 冒烟：F7、seed 3990、3,000 FE。

实验臂：

| 臂 | 入口 | 尺度 |
|---|---|---|
| V1-Frozen | `SGWO` | 共享 `sig` |
| SSSA | `SGWO_SSSA`，`sssaOn=1, sssaSwap=0` | G2: σ_G2；E: σ_E |
| SSSA-Swap | `SGWO_SSSA`，`sssaOn=1, sssaSwap=1` | G2: σ_E；E: σ_G2 |

3 臂 × 8 函数 × 10 种子 = **240 次运行**。

匹配脚手架运行时间对照使用 `SGWO_SSSA`，`sssaOn=0`，单独跑 80 次。

## 6. 晋级门槛

### H1：SSSA 相对 V1 有净收益

1. 跨函数中位最终误差比 ≤0.98；
2. 至少 6/8 个函数获胜；
3. 没有函数中位误差比 >1.20；
4. 运行时间相对 matched A3-Off ≤1.15 倍；
5. 报告逐函数配对 Wilcoxon 和 Holm。

### H2：来源匹配本身有独立贡献

SSSA 相对 SSSA-Swap：

1. 跨函数中位误差比 ≤0.98；
2. 至少 6/8 个函数获胜；
3. 没有函数中位误差比 >1.20。

如果 H1 通过、H2 不通过，只能写“两套尺度有效”，不能写“来源条件尺度校准有效”。

### H3：机制过程证据

必须报告：

- σ_G2 与 σ_E 随真实 FE 的均值和终点；
- `SigmaRatioMean = mean(σ_G2/σ_E)`；
- G2/E 单中心的评价数、成功样本数、成功率；
- G2/E 的成功改善幅度；
- 简单多峰、混合、组合函数分族结果；
- 运行时间与失败记录。

如果两条尺度长期相同，或者 G2 历史长期不足 5 个样本，必须报告为机制证据不足。

## 7. 淘汰规则

- H1 不通过：停止 SSSA，不扫描历史容量、最小样本数、初始尺度或下限。
- H1 通过、H2 不通过：只能声称双尺度有效，不能声称来源匹配有效。
- H1、H2、H3 全部通过：进入 29 函数、100k FE、30 个全新种子的正式确认。
- 不使用 3141–3150 作为最终测试种子。
- `main` 和冻结 `SGWO.m` 不动。
