## 1. 三臂设计（主假设 = C/B）

| 臂 | 系数采样（在筛选之后、只对获得评价名额的 G1 候选） |
|---|---|
| A | 原始 IID（冻结 G1+E+STEER，不重抽） |
| B | **post-selection IID**：同样时机、同样独立流、IID 重抽（实现/时序对照） |
| C | **post-selection LHS（SALS）**：同样时机、同样独立流、逐维分层重抽 |

两臂都保留 STEER（同触发概率、同随机方向，同一独立流），因此 **B 与 C 的唯一区别是 IID vs 分层**。

## 3. 预注册门槛

### H1（主假设，分层是否真有效）C/B

- 中位误差比 ≤0.98；≥11/15 个函数获胜；无函数 >1.20；运行时间比 ≤1.15。

### H2（对照实现是否中性）B/A

- 报告：中位比、胜负数、>1.20 个数。若 B/A 出现系统性偏差（中位比 ≥1.05 或 ≤0.95），
  先排查随机数耦合与实现细节，**不得**把 C/B 的差异归因于分层。

### H3（净收益）C/A

- 中位误差比 ≤0.98；≥11/15 个函数获胜；无 >1.20（应用价值）。

### 早期探索证据（决定主张强度，不作晋级门槛）

## 4. 判定

- H1 且 H3 通过 → `PROMOTE_SALS`：进入 29 函数 × 30 种子独立确认；
