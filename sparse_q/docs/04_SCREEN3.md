## SCREEN3 变体（8 函数 × 种子 3001:3005，D30/30k）

* **sq3a（钉死分配臂）**：S3p-q25（fixed 0.25, strat 采样）/ S4p-random（同窗口
  同动作集均匀重抽）/ S5p-q（6 态 × 3 动作 Q-learning）。
* **sq3b（加权随机臂）**：S3w-q25 / S4w-random / S5w-q（同上，weighted 采样）。

## 门槛（沿用 docs/01 §SCREEN3）

S5 相对同臂的 S3-best 与 S4-random 必须同时满足：中位比值 ≤ 0.99，
或（胜负 ≥ 6/8 且比值 ≤ 1.00）；并报告动作占比 / 状态访问 / 窗口奖励。
两臂分开判定；只有通过的手臂进入 10 种子复核与 FINAL。
若两臂都失败 → 删除 Q（报告负结果），最终形态为最优固定配额。
