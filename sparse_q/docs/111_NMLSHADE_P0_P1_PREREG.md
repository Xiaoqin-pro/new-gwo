# 111. Niche-Migration L-SHADE P0/P1 预注册

日期：2026-10-23　状态：**P0 失败，停止**

## 核心假设

L-SHADE 的主要弱点不是它不会收敛，而是收敛到平台后，外部档案中的已验证多样性没有被用于重启种群。NE-LSHADE 的“持续改变变异算子”已失败，因此本机制改成：

1. **VNB（Verified Niche Bank）**：从真实评价过的解中维护空间分离、质量受控的生态位库。
2. **PM（Plateau Migration）**：当真实 FE 窗口内全局最优的相对改进低于阈值时，将当前最差的一部分个体替换为 VNB 中的已验证解；不新增真实评价。
3. **精英保持**：只替换尾部个体，不改变全局最优和正常阶段的 L-SHADE 轨迹。

这不是更换 L-SHADE 的变异公式，而是一个零 FE 的“已验证生态位迁移”机制，可与 L-SHADE 的 pbest/archive/F/CR 记忆正交组合。

  - D `plateau_niche`：完整机制

### P0 晋级门槛

- D/A：中位误差比 `<=0.98`，至少 `6/8` 函数胜出，`>1.20` 不超过 1 个
- D/B：`<=0.99`，证明平台触发优于固定周期
- D/C：`<=0.99`，证明空间分离生态位库优于随机历史库
- D/A 平均时间比 `<=1.20`
- 任何未评价候选进入迁移库即失败
- migration 必须确实发生，且不能通过额外 FE 取得收益

## 消融对应关系

| 臂 | 已验证生态位 | 平台触发 | 说明 |
|---|---|---|---|
| A off | 否 | 否 | 原始 L-SHADE |
| B periodic_niche | 是 | 否（固定周期） | 分离触发时机 |
| C plateau_random | 否（随机历史） | 是 | 分离生态位库作用 |
