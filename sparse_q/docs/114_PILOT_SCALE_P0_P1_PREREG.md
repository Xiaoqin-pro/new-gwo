# 114. Scale-Normalized Pilot Racing P0/P1 预注册

日期：2026-10-23　状态：**P0 失败，停止**

## 机制

两个独立搜索核：

- **CMA-ES**：全局协方差适应，强于旋转/病态/低模态；
- **L-SHADE**：差分变异、pbest、archive，强于部分复合/多模态。

每核先运行 `pilotFrac=0.20` 的真实 FE（20k + 20k = 40k），记录已验证 pilot best 和初始化池的初始 best。然后按**尺度归一化规则**选择一个核，使用剩余 60k FE 从头完成搜索；总 FE 严格 100k。

### 冻结的选核规则（不是函数标签）

设
`cRel=(cBest-initBest)/initBest`，`lRel=(lBest-initBest)/initBest`（均按误差尺度截断为正值）。
仅当

1. `lBest < cBest`，
2. `lRel > 1e-8`，
3. `1e-7 < cRel < 1e-3`

选择 L-SHADE；否则选择 CMA-ES。这个规则只使用两个核在同一个函数上的 pilot 统计，不使用函数编号、D、最优值常量或人工分支表。
