# Stochastic Local Leadership (SLL) P0 预注册（2026-10-24）

## 机制

SLL 将每只狼的 α/β/δ 全部改为从其随机局部邻域中选出的已验证三只狼。邻域每代独立重抽，k=10；不读取距离、不读取特征、不读取档案，只保留标准 GWO 方程、E、STEER、K=10、M=100 和真实 FE 计费。该机制的正向解释是：随机局部邻域构成一个无偏的子群集集合，既避免全局三领导塌缩，又避免固定图拓扑带来的偏差。

## P0 协议

- CEC2017，D=50，100k FE。
- 8 函数：F1/F4/F7/F10/F13/F20/F24/F30。
- 5 个新种子：4271–4275。
- 5 臂 × 8 函数 × 5 种子 = 200 次，4 workers。
- 臂：
  - A-Global：标准全局三领导。
  - B-SLL10：随机局部三领导，k=10。
  - C-SLL20：随机局部三领导，k=20。
  - D-EuclidAll10：欧氏 kNN 全局部三领导，k=10。
  - E-GraphAll10：特征图全局部三领导，k=10。

## 固定门槛

1. `B/A` 中位误差比 ≤ 0.90，至少 6/8 胜，>1.20 不超过 1。
2. `B/D` 中位 ≤ 1.02，至少 5/8 胜。
3. `B/E` 中位 ≤ 1.02，至少 5/8 胜。
4. 运行时间 `B/A` ≤ 1.50。
5. 通过后进入 15 函数 × 10 种子 P1；不通过则局部领导家族彻底关闭。
