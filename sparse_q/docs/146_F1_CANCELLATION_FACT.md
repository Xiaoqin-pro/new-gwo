# 关键数学事实：g2F=1.0 时 r1 抵消（记录 2026-10-24）

## 事实

diffa 候选公式：`y = x_r1 + F·(α − x_r1) + F·(x_r2 − x_r3)`

当 **F=1.0** 时：
```
y = x_r1 + (α − x_r1) + (x_r2 − x_r3) = α + x_r2 − x_r3
```
**r1 完全抵消**（数值验证 max|yA1−yA2|=7e-12）。即：
- anchor=best 在 F=1.0 下是死代码（r1 不影响 y），解释其 dev 优势（0.678）无法在 29×30 复现；
- F1 单峰退化根因：候选从 α 出发加池内大跳 `x_r2−x_r3`，无 r1 的逐步精化；
- F=1.0 时候选分布完全由 α 和池内两点差决定，与 r1 无关。

## 推论

- **F<1.0 让 r1 恢复作用**：F=0.75 时 y = 0.25·x_r1 + 0.75·α + 0.75·(x_r2−x_r3)，r1 影响候选位置；
- **g2DiffScale<1.0 压差分噪声**：可独立于 F 压缩 `x_r2−x_r3` 项的幅度；
- 联合扫描 g2F × g2DiffScale 正在运行（screen287），目标：修复 F1 退化 + 保留多峰收益 + Holm 显著更好 ≥10。
