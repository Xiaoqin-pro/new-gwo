# 43. RGI 三臂确认预注册

## 0. 前置条件

RGI P0 已通过：8/8 函数有足够的可评价重启机会；触发候选实际被评价比例约 10%。因此进入三臂确认。

## 1. 三臂设计

| 臂 | 机制 | 来源 |
|---|---|---|
| A | 冻结 G1+E | `ablcore_20261017_062209` 的 A2-G1E，复用并已逐位复现 |
| B | RGI：连续失败且排名后半部分才随机移民 | 新跑 |
| C | StallRestart：只看连续失败，不限排名 | 新跑 |

- 29 函数：F1、F3–F30；
- 种子：3071–3100；
- 100,000 FE；
- G2 关闭，12 个槽位由标准 GWO 候选填补；E 配额 nE=38；K=10，M=100；
- 随机移民使用独立 `sRgi` 流；
- 其余筛选、档案、领导更新和真实评价预算完全一致。

## 2. RGI 主动规则

对每个 G1 个体维护真实评价连续失败计数：

- 若连续 ≥3 次评价的 G1 后代没有改善父代；
- 且当前已验证适应度排名位于最差 50%；
- 则下一次 G1 候选替换为边界内均匀随机移民；
- 如果该候选未被选中评价，不更新失败计数；
- 一旦被评价，按原 G1 语义更新父代、领导和档案，并清零失败计数。

C 臂只保留连续失败条件，不限制排名，用来检验排名门控是否必要。

## 3. 主要门槛

### H1：B 对 A 有净收益

- B/A 函数级配对中位误差比 ≤0.98；
- 95% bootstrap CI 上界 <1.00；
- 至少 18/29 个函数获胜；
- 没有函数中位误差比 >1.20；
- 运行时间比 B/A ≤1.15。

### H2：排名门控有独立价值

- B/C 中位误差比 ≤0.98；
- 至少 18/29 个函数获胜；
- 没有函数中位误差比 >1.20。

函数族和早期 FE 检查点必须全部报告。若 B 优于 A 但不能优于 C，只能声称“停滞重启有效”，不能声称“排名门控有效”。

## 4. 判定规则

| H1 | H2 | 判定 |
|---|---|---|
| 通过 | 通过 | `CONFIRM_RGI_RANK_GATED` |
| 通过 | 不通过 | `RGI_EFFECTIVE_RANK_NOT_NEEDED` |
| 不通过 | 通过 | `RANK_GATING_EFFECT_BUT_NO_NET_GAIN` |
| 不通过 | 不通过 | `STOP_RGI_CONFIRMATION` |

不扫描连续失败次数 3、排名比例 0.5 或移民分布。
