# 65. Sparse-DLH P0 几何审计预注册

日期：2026-10-22
状态：运行前冻结。

## 0. 机制（稀疏评价适配版 DLH）

冻结最终算法 G1+E+STEER（M=100、K=10、nE=38、100k FE）。只把 **12 个填充候选**改为 DLH 候选：

1. 仍先计算该槽位的标准 GWO 候选（`gwoMove`，消耗与原实现完全相同的基流随机数）；
2. 搜索步长 `R_i = ||X_i − X_i,GWO||`；
3. 动态邻域 `N_i = {j ≠ i : ||X_i − X_j|| ≤ R_i}`；
4. 维度差分候选 `X_DLH,d = X_i,d + r_d (X_n,d − X_q,d)`，`n ∈ N_i`（动态邻域），`q` 为种群中随机个体，`r_d ~ U(0,1)`；
5. 越界按仓库统一规则裁剪；
6. **不做原版的双候选真实评价比较**（那会额外消耗 FE）——DLH 候选只进入候选池，由原有随机筛选决定是否评价（12/100 → 平均每代 ~1.2 个名额）；
7. 匹配对照臂 `global`：同样的差分形式，但 `n` 也从整个种群均匀随机抽取（不使用动态邻域）。

随机数纪律：DLH 相关抽取使用**独立随机流**（`seed+777777`）；GWO 候选仍按原顺序消耗基流 →
各臂之间**只差 12 个填充槽位的位置**，归因干净。

## 1. 审计设计（P0，影子模式）

- CEC2017，D=50，100,000 真实 FE；STEER 开启；
- 8 个函数：F1、F3、F4、F7、F10、F13、F20、F30；
- 新种子：**3419–3423**（运行前扫描确认未使用）；
- 1 个审计臂 × 8 函数 × 5 种子 = **40 次运行**；
- `dlhMode='audit'`：计算反事实 DLH 候选并记录几何量，但**填充槽位仍用冻结的 GWO 候选** →
  轨迹与冻结算法必须逐位一致（合约测试）。

## 2. 记录指标（每 100 个槽位抽样一次）

| 指标 | 定义 |
|---|---|
| `DlhNeighMean` | 动态邻域规模 \|N_i\| 的均值 |
| `DlhNeighZeroFrac` | 邻域为空的比例 |
| `DlhDegFrac` | 位移 < 0.5% 跨度（退化差分）的比例 |
| `DlhDispMed` | \|\|X_DLH − X_i\|\|/span 中位数 |
| `DlhVsGwoMed` | \|\|X_DLH − X_i,GWO\|\|/span 中位数 |
| `DlhVsEMed` | X_DLH 到最近 E 中心的归一化距离中位数 |
| `DlhGwoVsEMed` | 同一槽位的 GWO 候选到最近 E 中心的距离中位数（对照） |

## 3. P0 通过条件（预注册，必须全部满足）

1. **邻域可用**：≥6/8 个函数，`DlhNeighMean` 中位数 ≥ 5；
2. **差分不退化**：≥6/8 个函数，`DlhDegFrac` 中位数 ≤ 0.30；
3. **几何有区别**：≥6/8 个函数，`DlhVsGwoMed` 中位数 ≥ 0.01；
4. **相对 E 不更冗余**：≥6/8 个函数，`DlhVsEMed` 中位数 ≥ 0.02（不贴着档案中心）；
5. **完整性**：`audit` 模式与 `SGWO_STEER3` 逐位一致（合约测试）。

## 4. 判定与停止规则

- 全部通过 → `PROMOTE_DLH_TO_P1`；
- 任一条不通过 → 停止 Sparse-DLH，不扫描邻域构造方式（`R_i` 的系数、固定半径等）；
- P1（另起批次）：A=冻结 G1+E+STEER、B=12 槽位 DLH、C=匹配全局差分对照，15 函数 × 10 新种子；
  门槛沿用仓库标准（中位比 ≤0.98、≥11/15 胜、无 >1.20、时间 ≤1.15），且 **B 必须优于 C**，
  否则不能把收益归因于"动态邻域"。
