## 假设

原始 L-SHADE 每代评价全部 N 个 trial；复杂问题上的瓶颈不是候选生成，而是 100k FE 内可用的代数和代表解数量。将候选池筛选与 L-SHADE 结合：

- 每代仍生成完整 N 个 L-SHADE trial，但不评价全部；
- 只评价 K 个代表候选，省下的 FE 用于更多代；
- 代表候选采用两势筛选：一半靠近当前最优（收敛势），一半用 farthest-point coverage（空间探索势）；
- 只对真实评价过的候选更新种群、pbest、外部 archive 和 F/CR 记忆。

Dense 模式必须与 `LSHADE_CEC` 逐位一致。
