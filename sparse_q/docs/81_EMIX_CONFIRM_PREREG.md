# 81. EMIX 确认级剂量-响应实验预注册（壳比例 0.00/0.25/0.50/0.75）

日期：2026-10-23　状态：**运行前冻结**

## 1. 为什么在 dev STOP 之后仍然做确认

- P0 诊断（`docs/79`，8 函数 × 5 种子 × 100k FE，被动逐位一致）：E 单中心壳 762,633 次评价仅 23 次全局最优改进（0.003%），
  E 两中心插值 758,079 次评价 2,280 次（0.301%）——**前提 8/8 通过，量级 100×**；
- P1（`docs/80`，15×10）：B(0.25)/A = 0.9815（8/15 胜、0 灾难）；D(0.75)/A = 1.0253（5/15 胜、3 灾难）；
  **同实现 B/D = 0.926、10/15 胜、Wilcoxon p=0.055**；C(0.00)/A = 0.9992（3 灾难，极端臂不安全）。
  → 呈**单调剂量关系**（壳越少越好，直到 0 处失效），但 dev 门槛（≥11/15 胜、无 >1.20）未过。
- 已有明确记录（§三十四）：该 dev 标尺对 ~3.5% 量级效应**两个方向都会错**（真 STEER 被否、噪声 MSE 被放行）。
  因此唯一有信息量的判定是确认级实验；**本实验即最终判定，不再有后续阶段**。

## 2. 设计（4 臂，同批，含冻结臂）

| 臂 | eShellShare | E 块模式 |
|---|---:|---|
| A | 0.50 | 奇数槽位为壳（与冻结终版**逐位一致**） |
| B | 0.25 | 每 4 槽位取 1 为壳 |
| C | 0.00 | 全部两中心插值 |
| D | 0.75 | 每 4 槽位取 3 为壳 |

协议：CEC2017 D=50、100,000 真实 FE、29 函数 [1 3:30]、**新种子 3584–3613**（运行前扫描）、
4 臂 × 29 × 30 = **3,480 次运行**（同批，含冻结臂，避免跨批次口径）。

## 3. 门槛与判定（运行前固定）

- **主假设（B/A）**：函数级配对中位误差比 ≤0.98；≥18/29 个函数获胜；**无函数 >1.20**；运行时间比 ≤1.15。
- **剂量-响应（次要但预先写定）**：逐函数配对比较 B 与 D（同实现、仅内部比例不同），
  要求 B/D 中位 ≤0.98 且 ≥18/29 胜（否则"壳越少越好"的因果解释不成立）。
- **安全性**：C、D 臂若出现 >1.20 的函数，如实报告为"极端配比不安全"的边界证据。

判定：
- 主假设 **且** 剂量-响应都通过 → `PROMOTE_EMIX`：EMIX（内部配比重构）作为可写入论文的机制；
- 仅主假设通过 → `EMIX_PARTIAL`：只能声称"B 优于冻结"，不得声称剂量机制；
- 主假设不通过 → `STOP_EMIX_CONFIRMED`：EMIX 线永久停止，不改比例、不改分支公式。
