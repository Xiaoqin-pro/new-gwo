# Q-Topo P0 预注册（2026-10-23）

## 机制

Q-Topo 在冻结的 GWO `G1+E+STEER` 框架上，只改变每 500 个真实 FE 窗口内 G1 的领导拓扑：

- 动作 1：全局 α/β/δ（原 GWO）。
- 动作 2：全局 α + kNN(5) 局部 β/δ。
- 动作 3：全局 α + kNN(10) 局部 β/δ。
- 动作 4：全局 α + kNN(20) 局部 β/δ。

状态为 FE 进度三档 × 真实停滞两档，共 6 个状态；奖励为窗口内全局最优相对改进加 0.1×有改进评价比例。Q-learning 只调度拓扑，不改候选生成、E、STEER、K、M、接受规则或真实 FE 计费。

## 预注册 P0

- CEC2017，D=50，N=50，K=10，M=100，100k 真实 FE。
- 8 函数：F1/F4/F7/F10/F13/F20/F24/F30。
- 5 个全新种子：4200–4204。
- 4 个 worker，160 次运行。
- 臂：
  - A-Global：固定全局领导。
  - B-QTopo：在线 Q 调度，ε 从 0.30 衰减到 0.05，学习率 0.1，折扣 0.9。
  - C-RandomTopo：每 500 FE 均匀随机选择同一动作集。
  - D-FixedKNN10：固定 kNN10 局部 β/δ。

## 固定门槛

1. `B/A` 中位误差比 ≤ 0.95，至少 6/8 函数胜出，>1.20 的函数不超过 1 个。
2. `B/C` 中位误差比 ≤ 0.95，至少 5/8 函数胜出，证明在线学习优于随机调度。
3. `B/D` 中位误差比 ≤ 0.98，至少 5/8 函数胜出。
4. 运行时间 `B/A` ≤ 1.25。
5. 不改变门槛；若失败，Q-Topo 线关闭，不进入 15×10 P1。

## 归因目标

A↔B：在线调度是否有效；C↔B：收益是否来自学习而非随机探索；D↔B：是否能超越单一 kNN 拓扑；动作分布用于解释策略而非替代性能门槛。
