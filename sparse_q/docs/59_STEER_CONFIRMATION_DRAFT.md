## 3. 判定

- H1 与 H2 同时通过 → `PROMOTE_STEER`，作为与 E 正交的第二机制进入论文；
- 仅 V/A2 或过程指标异常 → 先修实现再谈性能；

- 全部不通过 → 停止 STEER 方向，论文第二机制回到已确认非劣的 TSD-base 或单机制叙事。
