# 01 — 双目标：局部最优恢复 + 高效探索

## 问题 A：早熟收敛 / 局部最优
含义：领导同质化、种群塌缩后难以跳出当前盆地、长期消耗 FE 仍无显著进展。
- 观测：无改进 FE 长度、滚动最佳改善率、领导间距（除以边界对角线）、群体距离/分布、最后一次最优改善发生位置。
- **脱困**的操作性定义（不是数学上证明找到了局部最优）：在满足预先设定的“停滞条件”后，算法在接下来固定 FE 窗口内，出现可度量的真实 global-best 改善。所有算法使用相同定义。
- 主要指标：每 10k FE 的停滞窗口次数、停滞后恢复概率、恢复耗费 FE 的中位数、长期停滞占预算比例。若零停滞，报告“无事件”，不要将其计为 100% 逃逸。

## 问题 B：探索效率
含义：在同样 FE 下，更快识别有用的不同搜索区域，避免浪费在高冗余、无改进、重复访问上；同时控制产生候选/筛选的额外 CPU 代价。
- 早期有效性：在总预算 10/20/50% 的 best-so-far 误差、这些分位的 AUC/综合评分（均按相同 FE 采样）；不是单独比较最后精度。
- **有效新颖评价率**：真实被评价位置相对于历史已评位置满足归一化距离阈值、且（a）刷新了某个预先定义的 archive 新区域；（b）该区域在预设窗口内贡献真实改进的比例。须同时报告纯几何新颖率与其中成功率，防止“全随机点很新”虚高。
- `improving_FE_rate`：带来 global-best / pbest / archive 改进的真实评估数除以 FEs，分开计数，不能混用。
- `nonredundant_FE_rate`：真实评估位置与历史档案的最小距离超过阈值的比例。注意维度升高距离集中；辅以分位数标准化距离和 kNN 分位校准。
- `cost`：单次运行真实 wall-clock、总候选生成次数、每 FE 的额外距离/排序开销，报告在 CEC便宜目标与（可选）昂贵目标两种环境的成本。
- 不接受仅凭群体方差高/移动距离大就声称高效探索。**必须展示新区域与后续真实改善之间的关系**。

## 双目标不能互相替代
- 大扰动能增加新颖度，但可能毁掉 exploitation。必须确保整体同等FE精度与对强基线表现不退化。
- 减少种群多样性可能前期收敛更快，但停滞恢复更差。两套表格均要展示。
- 最终论文主指标仍是对强基线的同 FE 最优误差、稳定性、早期预算曲线和统计证据；行为指标是解释机制的证据，不是替代指标。

## 待预登记的科学假设（可拒绝）
H_A: 在近停滞/停滞窗口，新算法的恢复概率高于标准GWO/强GWO的同预算对照，而不恶化早期收敛。
H_B: 在预算前 50% 与全预算，新算法每次真实 FE 产生的有效改善/有用新颖探索比例优于相近机制和强基线，同时 CPU 开销保持合理。
H_AB: 结合模块可带来互补提升，超越单模块和固定/随机控制；若不成立，选择更简单的模块或宣告失败。
