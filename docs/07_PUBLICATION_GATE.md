# 07 — SCI 就绪度判断（不做未经证实的承诺）

## 哪类结果才值得写论文？
最低门：新方法正确；对标准GWO有进展；相比至少一个强GWO和强PSO/CSO在多函数上有令人信服的性能-时间 Pareto 优势；有效探索和停滞恢复分别有消融证据；完整披露负面函数。
更强门：在 D=50/D=100 和至少两类基准上有可复现优势，在完整排名中对多项强基线有不止偶然的竞争力，并证明核心机制优于“随机重启 / 固定调度 / 随机选点”等简单替代物。
这些是研究目标，不是必须同时满足的数学定理，也不能保证审稿结果。

## 强制写下不成立的边界
- 是否只赢标准GWO、仍显著输 HIDMS-PSO/HCLPSO/DMS-PSO？
- D=100 是否恶化？早期 AUC 改善是否换来了最后精度变差？
- 高新颖率是否没有有效进展？脱困触发是否只是更多随机点？
- 额外 CPU 工作是否使方法在便宜函数上明显变慢？
- 论文创新是否跟近年 RL-GWO、多种群/GWO-Laplace 论文过度重叠？

## 两段独立的核心贡献（若证据支持）
A. **Stagnation-aware recovery:** 检测失效状态，低预算风险地重新打开搜索空间，而不破坏精英；用真实恢复概率/FE 来支持。
B. **Productive exploration allocation:** 根据真实探索反馈减少重复/无价值评价，提升每 FE 高质量新区域发现率；用同 FE 早期质量与 useful novelty rate 来支持。
如任何一条无法得到实证支撑，必须改成单目标论文/继续实验，不能混成一句“平衡开发探索”。

## 审稿常见风险
比较对象弱化、历史实现错误、不同 FE、统计误用、测试泄漏、无效的“首次提出”、算法机制过度复杂、只看末端表、不看运行时间，以及无工程应用背景就宣称昂贵优化意义。
