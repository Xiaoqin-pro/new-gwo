## 0. 观测量定义（全部预注册）

* 预算单位：**真实 FE**（目标函数调用），初始化、重启、模块候选若被评价
  都计入；`EvalProbe` 独立计数并与算法自计数交叉核对。
* 停滞窗口 `W = max(50, 1%·budget)`（dev：30000 → W=300）。
* 无改善段：两次 global-best 严格改善之间的真实评价段（首段除外）。
* `RecoveryProbWindow`：长度达到 `W` 的段中，在额外 `R=4W` 次评价内出现
  真实改善的比例。
* `LongStagShare`：长度 ≥ W 的无改善段的总 FE / budget。
* `ImprovingFERate`：严格刷新 global best 的评价数 / budget（分四个
  1/4 区间报告）。
* 新颖度：候选相对"此前已评价位置的无偏采样档案（容量 200）"的最小
  归一化距离（除以搜索空间对角线）；采样规则：每第 5 次评价记录一次
  （预注册）。阈值 τ=0.01（1% 对角线）。
* `NovelUsefulRate`：每次 global-best 改善回溯 W 个真实评价，把窗口内
  最近的"新颖采样"记一次 credit（一对一）；比例 = 被记功新颖采样数 /
  新颖采样数。

## 1. 诊断结论（来自 diag1，D=30，30k FE，8 函数 ×5 种子；见 reports/diagnosis.md）

| 事实 | 数值（GWO → 强基线） |
|---|---|
| 长期停滞占预算比例 LongStagShare | GWO 0.862 → HCLPSO 0.359 / DMS 0.234 / HIDMS 0.470 |
| 停滞恢复窗口概率 | GWO 0.775 → HCLPSO 0.966 / HIDMS 0.893 |
| 恢复额外 FE 中位数 | GWO 502 → HCLPSO 145 / DMS 159 / HIDMS 207 |
| 新疑似评价的"有用率" | GWO 0.0095 → DMS 0.092 / HCLPSO 0.057 / HIDMS 0.051 |
| 末段 1/4 预算改善率 | GWO 0.0071 → DMS 0.083 / HIDMS 0.032 / HCLPSO 0.015 |

解释：GWO 的失败不是"不探索"（其新颖率 0.89 最高），而是**探索没有价值**
（99% 的新颖评价没有连接到任何真实改善）以及**停滞段又长又慢**；强基线
获胜的机制正好落在两个轴：(a) 恢复快（HCLPSO/HIDMS）；(b) 新疑似评价
的转化率高（DMS，约 10 倍于 GWO）。

## 2. 假说（可证伪）

* **H_A（停滞恢复）**：停滞触发的"新颖度重部署"（只重部署后半段、最久
  无改善的少量狼，目标点在候选池中取档案最近邻距离最大者）比 GWO 恢复更
  快、停滞占比更低，且不比 GWO 差；该收益来自"触发+目标选择"而不仅是
  "更多随机跳"。
* **H_B（探索效率）**：把"最不产出的狼"转为局部侦察狼（以最近成功步长
  中位数为尺度、候选池新颖度过滤），能提高单位 FE 的**有用**新疑评价率
  和末段改善率；自适应配额至少不差于最佳固定配额。
* **H_AB（组合）**：两个模块互补，E+S 不低于两个单模块中更强者，且两个
  指标族（恢复/有用新颖）同时改善。

## 3. 开发/测试隔离

* 开发集（允许反复观察）：D=30，maxFE=30000，函数 `[1 3 4 6 9 13 18 24]`
  （2 单峰 + 3 简单多峰 + 2 混合 + 1 复合），种子 3001:3005（一级），
  晋级后 3001:3010（二级）。
* 正式测试集（禁止用于调参）：D=50，maxFE=100000，F1、F3–F30（29 函数），
  种子 3001:3030。只有冻结版本与预注册消融进入正式批；正式批的强基线
  复用已审计的 30 种子表格（逐位可复现，见 reports/baseline_audit.md）。
* 统计：配对单位 (函数, 种子)；对数误差差的 Wilcoxon 符号秩检验；函数级
  Holm 校正；平均排名（先按函数中位数排名再平均）。开发集 5 种子时不做
  "显著性"声明，只报告比值与胜负。

## 4. 预注册门槛

### RD1（模块 E，S 关闭；单变量 = exploreMode/roverDest）

变体：GWO（参考）、E-fixed05、E-fixed10、E-fixed20、E-rand、E-adapt、
E-fixed10-nofilter（固定份额 + 无新颖度过滤，检验"过滤"本身）。

| 门槛 | 内容 | 判定 |
|---|---|---|
| B1 | 末段(1/4)改善率：E-adapt/GWO 的配对中位比值 ≥ 1.05，或 NovUsefulRate 比值 ≥ 1.20 | 必须 |
| B2 | 误差：E-adapt 对 GWO 的配对中位误差比 ≤ 0.98，或函数胜负 ≥ 6/8 且比值 ≤ 1.00 | 必须 |
| B3 | 自适应 vs 最佳固定：若最佳固定比 E-adapt 的比值好 ≥2%，则**改用固定份额**并在报告中记录"自适应未被数据支持" | 决定形态 |
| B4 | CPU：E-adapt 平均单次运行 ≤ 3× GWO | 必须 |
| B5 | 过滤有效性：E-fixed10 与 E-fixed10-nofilter 比较（比值/胜负），报告 novelty 过滤是否贡献；若 nofilter 更好则去掉过滤 | 决定形态 |

晋级：B1∧B2∧B4 通过 → 进入 RD2/RD3 与 10 种子复核；否则模块若失败，
按 docs/03 的规则淘汰或提出**新**的可证伪假说（计入配置预算）。

### RD2（模块 S，E 关闭；单变量 = recoveryMode/recoveryDest）

变体：GWO、S-stag-nov、S-stag-rand、S-per-nov。

| 门槛 | 内容 | 判定 |
|---|---|---|
| A1 | RecoveryProbWindow（按事件聚合）比 GWO 提高 ≥ +0.05 绝对值（GWO=0.775 → ≥0.825） | 必须 |
| A2 | LongStagShare 比 GWO 降低 ≥ 0.05 绝对值（≤0.812） | 报告 |
| A3 | 误差：对 GWO 配对中位比值 ≤ 1.00 且函数胜负 ≥ 5/8 | 必须 |
| A4 | 机制特异性：S-stag-nov 相对 S-stag-rand 与 S-per-nov 至少一项占优（恢复概率 +0.03 或比值 ×0.98） | 决定形态 |

晋级：A1∧A3 → 保留；若 A4 不成立 → 保留最简可行形态并记录负结果。

### RD3（组合；单变量 = 组合本身）

变体：GWO、E*、S*、E*+S*（E*/S* 为 RD1/RD2 胜者）。

| 门槛 | 内容 |
|---|---|
| AB1 | E*+S* 对 GWO 的配对中位比值 ≤ min(E*,S*) 的比值，且 ≤ 1.00 |
| AB2 | 恢复指标 ≥ S* 的 95%，有用新颖率 ≥ E* 的 95%（双轴不互相牺牲） |
| AB3 | 若组合不满足 AB1 → 采用两个单模块中的更强者作为最终形态 |

### 正式批门槛（冻结后）

1. 与已审计 30 种子表格合并后，对标准 GWO 函数级胜负 ≥ 20/29，
   且配对检验 Holm 后至少 3 个函数显著更好、0 个显著更差；
2. 对 ≥1 个强非 GWO 基线（HIDMS/HCLPSO/DMS/SAQ-CSO）在中位误差比上
   进入 1.3 倍以内或函数胜负 ≥ 10/29；
3. 双轴证据：相对 GWO 的 RecoveryProbWindow 提高且 LongStagShare 降低，
   且末段改善率/有用新颖率提高（正式批同协议统计）；
4. FE 审计零违规、无基线改动、运行时间如实报告。

## 5. 预算与停止

* 配置上限 50（每个 (变体 × 参数) 计 1），时间上限 10 小时；连续 3 批
  无稳健增益 → 停止模块迭代，转入"报告不足 + 写清楚"的收尾。
* 负面结果全部保留在 experiments/registry.csv 与 reports/ 中，不删除。
