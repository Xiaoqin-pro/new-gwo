# SCI Readiness — LLT（局部领导拓扑）

日期：2026-10-22

## 结论

**LLT 的前提成立、效应显著，但 ring 版本按项目预注册标准不晋级（2 个函数 >1.20，且 Holm 校正后显著的
两个函数都是退化）。是否可作为论文机制，取决于 rank 门控版本能否消除尾部退化。**

| 主张 | 证据 | 状态 |
|---|---|---|
| 稀疏评价下评价名额被近邻重复候选占用 | P0：每代被选 10 个候选中 20.0%–31.5% 距离 <2% 跨度（8/8 函数） | 成立 |
| 环路局部领导会实质改变 G1 候选几何 | P0：反事实位移中位 0.017–0.050 跨度，局部≠全局比例 0.98–0.996 | 成立 |
| LLT 显著降低最终误差（均匀） | P1：B/A 中位 0.794、11/15 胜，但 F3 1.598、F30 1.354（Holm 显著）；函数级 Wilcoxon p=0.064、Friedman p=0.247 | **不成立（函数族间的重新分配，整体不显著）** |
| "局部质量"贡献独立于结构 | P1：B/C 中位 0.976、9/15 胜、无显著函数 | 未证实 |
| LLT 与 E 正交可消融 | P1：D/E 中位 0.835、12/15 胜，交互 CI 包含 0 | 初步支持 |

## 可写入论文的部分（若 rank 版本成立）

- **机制**：固定环形局部领导拓扑（w=7、best-3），逐狼领导集合，简单、零额外 FE；
- **前提证据**：近邻重复率 20%-31% 的审计（稀疏评价把名额浪费在冗余候选上）；
- **族依赖证据**：多峰 0.785、混合 0.741 受益，单峰 1.312 受损 → 论文里必须作为"多样性-收敛权衡"呈现，不能写成均匀提升；
- **前提证据**：近邻重复率 20%–31% 的审计（这是"稀疏评价把名额浪费在冗余候选上"的直接证据，本身就是论文素材）；
- **消融**：E × LLT 五臂设计，含环路随机领导匹配对照。

## 风险与限制

- ring 版本在 F1/F3/F30 上退化，必须在手稿中如实报告，或由 rank 门控版本替代；
- B/C 仅 0.976（9/15 胜）→ 不能声称"局部质量"是关键，只能声称"环路结构 + 质量选择"；
- 与 PSO 的 lbest/ring 拓扑、GWO 的多领导/邻域变体存在先例，创新点必须收窄为
  "稀疏真实评价协议下、固定环形窗口的逐狼领导集合 + 匹配随机领导对照"。

## 后续（已判定）

- rank 门控版本 dev **不晋级**（m=0.9921、8/15 胜、c=1.4077）；ring 版本在新种子块上也不复制（0.984 vs 0.794）；
- **停止 LLT 全部变体**，不进入 29×30 确认；
- 可写入论文的只有两块：① 近邻重复率 20%–31% 的**前提审计**；② "领导局部化在函数族之间重新分配性能、
  且收益不可复制"的**设计边界**。不能写成 LLT 提升性能。
