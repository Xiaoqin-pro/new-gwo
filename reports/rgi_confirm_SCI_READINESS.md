# SCI Readiness — RGI Confirmation

## 结论

**RGI 没有通过相对 G1+E 的净收益门槛，不能作为第二项机制贡献。**

| 条件 | 阈值 | 实测 | 判定 |
|---|---:|---:|---|
| B/A 中位比 | ≤0.98 | 1.034 | 不通过 |
| B/A CI 上界 | <1.00 | 1.057 | 不通过 |
| B/A 胜场 | ≥18/29 | 8/29 | 不通过 |
| B/A 灾难性退化 | 0 个 >1.20 | 5 | 不通过 |
| B/C 中位比 | ≤0.98 | 0.7065 | 通过 |
| B/C 胜场 | ≥18/29 | 28/29 | 通过 |
| B/C 灾难性退化 | 0 个 >1.20 | 0 | 通过 |

## 机制结论

- 排名门控相对无门控停滞重启是有效的：B/C 中位比 0.706、28/29 胜；
- 但 RGI 相对冻结 G1+E 总体退化，B/A 中位比 1.034、8/29 胜、5 个函数 >1.20；
- 因此“排名门控有价值”和“RGI 有净收益”是两个不同结论，不能混写。

## 论文建议

- 不写 RGI 提升最终性能；
- 保留 RGI/StallRestart 作为设计边界：条件门控能改善重启策略本身，但重启动作不适用于当前 G1+E 框架；
- 最终算法采用 G1+E；
- 不再扫描连续失败次数、排名比例或重启方式。
